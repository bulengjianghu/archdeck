# 专题：工作台界面

> 回答：页面怎么布置、每个组件画什么、交互意图怎么上交。
> 覆盖模块：呈现层全部。呈现层只读视图状态的派生数据、只调 DeskState 的操作，不做投影、布局与规则计算（[03-architecture.md §3.5](../03-architecture.md#35-模块边界的判据)）。界面行为对应的规则见 [02-domain.md](../02-domain.md)，需求编号见 [01-requirements.md](../01-requirements.md)。

## 1. 页面与路由

| 路由 | 页面 | 说明 |
|---|---|---|
| `/` | 项目列表 | 读 `projects.json`；每个项目一张卡片，卡片下列出推进中的设计版本（打开最新一轮），已归档的只注明个数（DV-6）；任一项目描述变化后刷新 |
| `/p/<项目>` | 项目视图（当前版本） | 按项目 + 版本创建并注入 DeskState |
| `/p/<项目>/d/<设计>/<轮次>` | 项目视图（设计版本） | 同上 |

切换项目或版本时重建项目视图，每个项目的每个版本一份独立状态；查询参数见[视图状态与协调 §3](./view-state.md#3-会话规则视图状态转移)。

## 2. 项目视图布局

```text
┌ 顶部栏：导航树折叠 · 版本切换 · 视角切换 · 面包屑 · 搜索 · 显示开关 · 专注 · 面板折叠   ┐
├ 设计信息条（仅设计版本）                                                                 ┤
├ 导航树 │ 分隔条 │ 画布区（分屏容器）                              │ 分隔条 │ 属性面板 ┤
│ 模块 / │        │   结构图（画布）  │  副栏：时序图 ｜ 源代码      │        │          │
│ 文件 / │        │   （左右排列；可切换为上下）                     │        │          │
│ 步骤   │        │                                                  │        │          │
│        │        ├ 回放控制条（运行视角）                           ┤        │          │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

- 导航树与属性面板的宽度可拖动、可折叠，宽度与折叠状态记在本地（W-1）。「专注」一键收起两者；两者都已收起时再按一次恢复。
- **舞台显示**（V8、V9，`stage/useStageDisplay.ts`）：静态关系显示方式（按项目记在本地）与「在画布上显示」的临时对象只属于画布这块界面，由项目视图创建并注入，画布读取、面板写入；播放头、焦点、层次任一变化即清除临时对象。
- **分屏容器**（W-4，`split/SplitView.vue` + `split/paneLayout.ts`）：按可序列化的布局树 `PaneLayout` 排布视图，视图组件只按槽位（`structure` / `aside`）挂载，不知道自己的位置。
  - 提供「两块、方向可切换（默认左右）、比例可拖、副栏可收起」。左右排列时，收起的副栏缩成一条竖栏。
  - **副栏**（`split/AsidePane.vue`，页签与预览文件的规则在 `split/useAside.ts`，G15）：标题栏为收起、页签「时序图」（运行视角）「源代码 · <文件名>」（有预览文件时，带关闭）、分屏方向切换；内容为时序图（§5）或源代码预览（§6）。运行视角或有预览文件时出现。页签与预览文件只属于这块界面，不进视图状态与 URL：选中文件 → 切到「源代码」并预览它；打开场景、移动播放头 → 切到「时序图」；关闭预览后结构视角下副栏消失。
  - 方向、比例、收起按项目记在本地，不进视图状态与 URL。
  - 以后的自由拖拽只扩展布局树的编辑操作。

```ts
type PaneLayout =
  | { kind: 'pane'; slot: 'structure' | 'aside'; collapsed?: boolean }
  | { kind: 'split'; dir: 'row' | 'column'; sizes: number[]; children: PaneLayout[] }
// 操作：resize（拖比例）· toggleSlot（收起 / 展开）· setDirection（左右 / 上下）
// 本地存储沿用旧值：槽位名 sequence 读出时改为 aside
```

## 4. 画布（结构图）

把带坐标的层次视图转成 Vue Flow 节点与边，直接写入其 store（属性同步在「上一层有选中、切回总览」时会被跳过）。

| 方面 | 做法 |
|---|---|
| 节点 | 模块（职责摘要、可下钻标识、目标态虚线）、边界节点（外部模块与所在路径）、带（层名、抽象原则、可依赖层）、核心模块、`+N` 占位；参与者节点（按类别图标）与边界框；运行视角下的步骤序号与分支预览序号（小节点，单击指向 / 选分支） |
| 边 | 按走线画折线或曲线；颜色按关系类型，线宽随聚合条数增加，异步为点划线 |
| 文件高亮 | 选中文件时，`fileNodes` 给出的节点加文件高亮描边（G14）；归属模块是当前层次本身时不高亮，提示在文件面板 |
| 聚焦与变淡 | 结构视角：焦点为悬停优先、其次选中；与焦点不相邻的节点和边变淡；分层总览里带不参与变淡；核心跨层边只在聚焦核心模块时出现（O4）；边界边只在聚焦其一端或被选中时出现（L4）。运行视角由舞台显示与焦点突出决定（下两行） |
| 适应画布 | 内容外框取自布局结果，运行视角隐藏静态内容时只取可见节点；切换层次、切换显示方式、画布容器尺寸变化（进入运行视角、切换分屏方向、拖动分隔条、折叠两侧栏）后重新适应 |
| 设计版本标记 | 新增 / 修改的节点描边并带角标，「△N」表示涉及变更数；含新增 / 修改关系的边加底色 |
| 舞台 | 运行视角下布局不变；`stageDisplay(视图, 参与节点, 叠加, 显示方式, 临时对象)` 给出每个节点与边是显示、淡化还是隐藏（V5）：参与节点取时序模型的泳道（本层全部分支的帧端点），只在未选分支 / 未到达处出现的淡化；回放边（走过、当前、预览、悬停预览、未建模）始终显示；其余节点与静态边按显示方式隐藏 / 淡化 / 照常（V8）；「在画布上显示」的对象（V9）的静态边及对端节点照常显示；带与边界框始终显示。画布左下角（缩放按钮旁）切换显示方式。舞台视图补齐场景端点（P12），不受显示开关影响（L9） |
| 焦点突出 | `emphasisOf` 给出突出的可见消息（R15）：这些消息所在的边与端点照常，其余走过的边与步骤序号淡为灰色；无突出时按原样 |
| 回放叠加 | 数据来自 Layout 的 `stageOverlay`。当前可见消息的边沿步骤方向流动（可与箭头相反，P10），端点节点为活动态；走过的边保留并标步骤序号；内部活动只高亮节点；落在核心跨层边上时临时显示该边（P7）；经过的边界边显示；无视图边时画「结构中未建模」临时虚线（P11）；停在分支点时各选项首条消息的边以虚线预览并标选项序号；当前帧本层不可见时提示并可跳到能看到它的层次（R11）；悬停时序图消息时预览其落点 |
| 交互 | 单击节点 / 边 → 选中（运行视角下即钉住，V3）；单击空白 → 取消选中（N13、V4）；双击 → 下钻或跳到边界节点所在层次；悬停 → 高亮相邻；单击步骤序号 → 指向该步（R13）；单击分支预览序号 → 选分支；悬停不弹提示框（W-1） |

## 5. 时序图

只画定位好坐标的时序模型（见[场景投影与回放 §7](./scenario.md#7-时序模型与时序图排布)）：

- **泳道与消息**：参与者头部与生命线；泳道按层次顺序（P9），同一父模块的泳道头上方有分组框标父模块名（P13）；外部参与者在最左，竖线隔出系统边界；同步实线实心箭头、异步虚线开放箭头、显式返回（R2、S10a）；内部活动画成激活条。
- **组合框**：左上角标类型；`loop` 标条件，`par` 标「并行（串行回放）」，`ref` 显示被引用场景名；`alt` 显示全部分支与条件，已选正常、未选淡化、未到达全部淡化，每个条件是可单击的页签（已选的加下划线）；折叠的框缩成一行（P6）。
- **焦点突出**（R15）：有突出时，突出的消息照常（当前消息强调色），其余路径上的消息变灰，未选分支与未到达的更淡。
- **交互**：单击消息（含未选分支上的）→ 指向该步（R13）；单击 `alt` 的分支条件 → `chooseBranch`（F6e）；当前消息高亮并滚动到可见；悬停消息时在结构图上预览对应的边；本层看不到任何帧时提示并提供「跳到场景所在层次」（R5）。
- **头尾固定**（D-2）：泳道头（含分组框与系统边界线）固定在顶部，底部另有一份泳道头，消息区夹在中间纵向滚动；三者在同一个滚动容器里，横向滚动时一起移动。
- **滚动**（D-7）：只在用户移动播放头（单步、指向、拖动进度、回到开头，含改选分支使播放头移动）后把当前步骤滚到纵向中间；悬停、选中、切换层次、重新加载都不滚动。信息条上的「定位」按钮把当前步骤滚到中间。
- **无悬停弹出**（W-1）：泳道头、消息、分支条件都不弹提示，信息在属性面板查看。
- **信息条**：当前层次名、当前帧本层不可见时的提示（R11）；收起、页签与方向切换在副栏标题栏（§2）。

## 6. 源代码预览

`source/SourceView.vue`（SR-8、G17）：只读显示预览文件。顶部为路径、归属模块（可定位）、行数；正文为 Shiki 按扩展名高亮的代码与行号（与签名高亮共用 `panel/highlight.ts`，按需加载语法；不认识的扩展名、超过 20 万字符的文件显示纯文本，仍带行号）。过大、二进制、文件不存在、源码不在本地、构建态时给提示。没有编辑、保存、跳转定义等 IDE 功能。

## 7. 回放控制条

上一步 / 下一步（按本层可见消息，R7）、进度条拖动到已走路径上的任意位置；显示「第 i / N 步」，停在开头时 i 为 0，分支点之后未定时为「≥ N」（F6d）。**路线总览**（F6f）：`routeOf` 给出的分支点依次显示为「序号 · 所选条件 ▾」，下拉列出全部条件，改选即 `chooseBranch`；待选的分支点显示「待选」；改选丢弃了其后的选择时，在路线旁提示「已重置其后 n 个分支选择」数秒。到达分支点时另外展开全部选项（条件 + 首条消息）供选择，未选时「下一步」不可用。不提供自动播放（R1）。键盘：← → 单步，数字键选分支。

## 8. 属性面板

按**焦点**分派（V2）：结构视角为选中，否则当前父模块（根层为系统）；运行视角钉住时为选中对象，跟随时为当前步骤（停在开头时为场景）。

| 面板 | 内容 |
|---|---|
| 系统 | 简介、生成来源、规模、顶层模块；设计版本时顶部为设计面板：设计目标、本轮说明、待确认问题、按实体分组的变更清单（可跳转，删除项只列出）、各轮评审意见与轮次切换 |
| 模块 | 职责、实现原理、对外接口、核心数据结构、子模块、出边 / 入边、代码与文档引用；**源代码**一节：文件（子树并集，可选中，标出直接归属的子模块）、入口文件（来源：描述 / 约定 index.ts / package.json）、入口导出与 `provides` 的对应（已对应 / 导出未描述 / 描述未导出，G12）；源码不在本地或构建态时只提示；层另有抽象原则、包含 / 不包含、可依赖的层 |
| 关系 | 两端、类型、同步 / 异步、经由接口、数据结构、说明；不在当前视图时「定位到所在层次」 |
| 聚合边 | 原始关系与各类型条数，可逐条定位 |
| 参与者 | 名称、类别、说明、入口关系、由它触发的场景 |
| 文件 | 路径；归属模块（可定位，冲突时全部列出并标「归属冲突」）或「未归属」（提示补 `codeRefs` 或写进忽略清单）/「已忽略」；是哪些模块的入口；当前层次中的投影说明（G14）；导出（名称、类别、签名，对应到接口的标出接口）；「预览源码」（重新打开副栏预览） |
| 场景（跟随且停在开头时） | 说明、触发者与原因、场景所在层次（可跳转）、参与模块、ref 的引用与被引用；步骤目录见导航树的步骤树（§9） |
| 步骤（跟随时） | 头部：序号、标签、类型、所在组合框与分支条件。依次：**作用**（标签与说明）；**输入**（本步携带的数据）；**输出**（配对返回的数据与标签，可指向该返回；本步就是返回时为「回应」配对的调用；异步为「不等待返回」；没有显式返回时为「隐含返回，见接口签名」，F7）；数据结构（可展开）；经由接口；真实端点与本层投影；本层一条可见消息覆盖多帧时列出这些帧；**结构关系**（默认折叠：对应关系，推断时标「推断」；「在画布上显示」，V9）；出处 |

- **运行信息**（V6，`RunSection.vue`）：运行视角下模块、关系、聚合边、参与者面板顶部的一节（文件面板没有运行信息）——本场景中参与的步骤（可指向，标出离播放头最近的一步）、在本层收发的消息、用到的接口与数据；面板原有的结构信息折叠在其下方；模块与参与者另有「在画布上显示结构关系」（V9）；顶部提示「已钉住」及如何回到跟随。
- **设计版本标记**：标题处的新增 / 修改标记与「改了哪些字段」；`designNote` 显示为「设计说明」。
- **内容组件**：Markdown（禁用原始 HTML）、TS 代码高亮（按需加载 Shiki）、接口与数据结构折叠项、关系行、分节。

## 9. 导航树

左侧固定栏（W-7，`tree/**`），三个页签：「模块」「文件」始终可用，「步骤」只在运行视角出现；进入运行视角切到「步骤」，退出切回「模块」，选中文件切到「文件」（T1）。页签、展开状态、宽度只属于这块界面，不进视图状态与 URL。

| 页签 | 内容 | 同步（状态 → 树） | 操作（树 → 意图） |
|---|---|---|---|
| 模块 | 系统为根的模块树，层按 `order`；目标态模块虚线标记；结构视角下「只看现状」开启时不列目标态模块（T2） | 当前层次的祖先链展开并标出当前层次；选中的模块高亮、展开到它并滚到可见（T3）；选中文件时归属模块标出并展开到它（G14）；运行视角下标出参与模块（`scenarioModules`）与当前步骤的两端（T5） | 单击 → `revealModule`（N4），系统 → `goTo(根)`；双击有子模块的 → `drillInto`；悬停本层可见的模块 → `setHover`（T3、T4） |
| 文件 | 目录树 `fileTree`：目录可折叠并显示文件数与未归属数；文件行标出未归属（警告色）、归属冲突、已忽略（灰），内部文件全部忽略的目录同样标灰（G18）；顶部为源码根目录、「只看未归属」筛选与「刷新」；源码不在本地、构建态时只显示提示（G1、G2） | 选中模块：其文件高亮，所在目录标点并展开到第一个文件（G13）；选中文件：该行高亮、展开到它并滚到可见 | 单击文件 → `select({ kind: 'file' })`（G16）；单击目录 → 展开 / 折叠 |
| 步骤 | 步骤大纲 `outlineScenario`：组合框（`loop`、`par` 分支、`ref`）为可折叠的分组，`alt` 列出全部分支与条件，空分支占位，帧显示「A → B：标签」（T6） | 帧标出已走过 / 当前 / 未走到 / 未选分支 / 未到达；本层可见的帧显示可见消息序号，不可见的标「本层不可见」；当前帧滚到可见（T7） | 单击帧 → `seek`（R13）；单击 `alt` 分支标题 → `chooseBranch`（F6b）；悬停帧 → 在结构图上预览落点（同时序图）（T8） |

## 10. 其他

- **问题提示**：列出描述的错误与提醒，展开可见文件与行号（W-6）。
- **图例**：关系类型的颜色与线型、聚合线宽、可下钻与目标态样式；运行视角追加当前步骤、已走过、内部活动、分支预览、未建模、同步 / 异步，以及当前的静态关系显示方式。
- **键盘**：Esc 先取消选中再返回上级（N9）；Backspace 返回上级，根层回项目列表（N7）；运行视角下 ← → 单步、数字键选分支。

| 模块 | 组件 |
|---|---|
