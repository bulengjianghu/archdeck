# 专题：工作台界面

> 回答：页面怎么布置、每个组件画什么、交互意图怎么上交。
> 覆盖模块：呈现层全部。呈现层只读视图状态的派生数据、只调 DeskState 的操作，不做投影、布局与规则计算（[03-architecture.md §3.5](../03-architecture.md#35-模块边界的判据)）。界面行为对应的规则见 [02-domain.md](../02-domain.md)，需求编号见 [01-requirements.md](../01-requirements.md)。

## 1. 页面与路由

| 路由 | 页面 | 说明 |
|---|---|---|
| `/` | 项目列表 | 读 `projects.json`；每个项目一张卡片，卡片下列出推进中的设计版本（打开最新一轮），已归档的只注明个数（DV-6）；任一项目描述变化后刷新 |
| `/p/<项目>` | 项目视图（当前版本） | 按项目 + 版本创建并注入 DeskState |
| `/p/<项目>/d/<设计>/<轮次>` | 项目视图（设计版本） | 同上 |

切换项目或版本时重建项目视图，每个项目的每个版本一份独立状态；查询参数见[视图状态与协调 §3](./view-state.md#3-会话规则视图状态转移)。

## 2. 项目视图布局

```text
┌ 顶部栏：导航树折叠 · 版本切换 · 视角切换 · 面包屑 · 搜索 · 显示开关 · 专注 · 面板折叠   ┐
├ 设计信息条（仅设计版本）                                                                 ┤
├ 导航树 │ 分隔条 │ 画布区（分屏容器）                              │ 分隔条 │ 属性面板 ┤
│ 模块 / │        │   结构图（画布）  │  副栏：时序图 ｜ 源代码      │        │          │
│ 文件 / │        │   （左右排列；可切换为上下）                     │        │          │
│ 步骤   │        │                                                  │        │          │
│        │        ├ 回放控制条（运行视角）                           ┤        │          │
└──────────────────────────────────────────────────────────────────────────────────────────┘
```

- 导航树与属性面板的宽度可拖动、可折叠，宽度与折叠状态记在本地（W-1）；导航树的收起按视角分别记（`nav-collapsed` / `nav-collapsed:run`），运行视角缺省收起，视角切换时取该视角记下的状态。「专注」一键收起两者；两者都已收起时再按一次恢复。
- **舞台显示**（V8、V9，`stage/useStageDisplay.ts`）：静态关系显示方式（按项目记在本地）与「在画布上显示」的临时对象只属于画布这块界面，由项目视图创建并注入，画布读取、面板写入；进度、选中、层次任一变化即清除临时对象。
- **分屏容器**（W-4，`split/SplitView.vue` + `split/paneLayout.ts`）：按可序列化的布局树 `PaneLayout` 排布视图，视图组件只按槽位（`structure` / `aside`）挂载，不知道自己的位置。
  - 提供「两块、方向可切换（默认左右）、比例可拖、副栏可收起」。左右排列时，收起的副栏缩成一条竖栏。
  - **副栏**（`split/AsidePane.vue`，页签与预览文件的规则在 `split/useAside.ts`，G15）：只有一栏标题栏——收起、页签「时序图」（运行视角）「源代码 · <文件名>」（有预览文件时，带关闭）、时序图页签下的「本层不可见」提示、「定位」（当前层次已在面包屑中，不重复）（调用时序图暴露的定位方法）与「图例」（时序图图例浮层：同步 / 异步 / 返回的线型与箭头，ADR-0017）、分屏方向切换（ADR-0010）；内容为时序图（§5）或源代码预览（§6）。运行视角或有预览文件时出现。页签与预览文件只属于这块界面，不进视图状态与 URL：选中文件 → 切到「源代码」并预览它；打开场景、移动进度 → 切到「时序图」；关闭预览后结构视角下副栏消失。
  - 方向、比例、收起按项目记在本地，不进视图状态与 URL。
  - 以后的自由拖拽只扩展布局树的编辑操作。

```ts
type PaneLayout =
  | { kind: 'pane'; slot: 'structure' | 'aside'; collapsed?: boolean }
  | { kind: 'split'; dir: 'row' | 'column'; sizes: number[]; children: PaneLayout[] }
// 操作：resize（拖比例）· toggleSlot（收起 / 展开）· setDirection（左右 / 上下）
// 本地存储沿用旧值：槽位名 sequence 读出时改为 aside
```

## 4. 画布（结构图）

画什么由 Layout 的纯函数 `canvasScene(input)`（`src/layout/canvas.ts`，ADR-0013）算出：输入为带坐标的层次视图、模型索引、选中与悬停、舞台叠加与显示方式、选中突出、设计版本差异、文件高亮；输出为节点与边（位置、类型、数据、类名、层级）以及适应画布用的可见节点。下表各行描述的就是它的规则。GraphCanvas 只把结果直接写入 Vue Flow 的 store（属性同步在「上一层有选中、切回总览」时会被跳过）、把交互转成操作、适应画布。

| 方面 | 做法 |
|---|---|
| 节点 | 模块（职责摘要、可下钻标识、目标态虚线）、边界节点（外部模块与所在路径）、带（层名、抽象原则、可依赖层）、核心模块、`+N` 占位（单击临时展开为该层全部模块、变为「收起 N 个」，O6；z 序在核心跨层边之上）；带宽按画布宽度铺开（画布以 ResizeObserver 把宽度交给 `desk.setCanvasWidth`，换算成带内列数，O7）；参与者节点（按类别图标：用户在系统框上方、外部系统与时间在右侧，A7）与边界框（根层为系统框；下钻后外框为系统、内框为当前父模块，边界节点在两框之间，`FrameNode`）；运行视角下的步骤序号与分支预览序号（小节点，单击指向 / 选分支） |
| 边 | 按走线画折线或曲线：普通层次全部正交折线（端口上进下出，L11；边界边显示时才按需走线，L4；画出来的框外边各占一条轨道、标签不相碰；同一侧左动右静——动态关系的出入点在左半、静态在右半），交叉处水平段起半圆小桥（跳线）；曲线只用于分层总览的核心跨层边与参与者的边、回放临时线与代码依赖叠加线。同一对节点之间按关系类型各一条（L5），平行的曲线按序号错开。层级：与聚焦对象相邻、选中、回放经过的边浮在节点之上（`EDGE_Z`），其余在模块节点之下；步骤徽标、分支预览与「+N」占位块再高一档。编码一个通道一个维度（L10、ADR-0018）：颜色 = 关系类型（`--rel-*`，运行时饱和、`depends` / `implements` 低饱和且更细）；线型 = 事实状态（实线 / 未证实虚线 / 叠加线点线，K9）；箭头 = 同步实心、异步空心「V」、`implements` 空心三角（`ArrowMarker`，`RouteEdge` 与图例的 `LineSwatch` 共用；大小随线宽档 `arrowSize`，线按 `retractEnd` 回缩一个箭头深度，颜色跟随线色）；线宽 = 聚合条数三档（`RouteEdgeData.weight`）；标签只有聚合边的 `×N`（带边框 pill）与异常标记，不写类型名——elk 为每条直接边申请至少 24×18 的标签槽，没给出可用坐标时画布按走线中点放（`routeMidpoint`）；平行边终点重合时在目标节点边缘错开（`spreadEnds`）；选中为强调色窄晕（线宽不变）；违规红晕优先于设计变更底色 |
| 文件高亮 | 选中文件时，`fileNodes` 给出的节点加文件高亮描边（G14）；归属模块是当前层次本身时不高亮，提示在文件面板 |
| 聚焦与变淡 | 结构视角：聚焦对象为悬停优先、其次选中；与聚焦对象不相邻的节点和边变淡；分层总览里带不参与变淡；核心跨层边只在聚焦核心模块时出现（O4）；边界边只在聚焦其一端或被选中时出现（L4）。运行视角由舞台显示与选中突出决定（下两行） |
| 适应画布 | 内容外框取自布局结果，运行视角隐藏静态内容时只取可见节点；切换层次、切换显示方式、画布容器尺寸变化（进入运行视角、切换分屏方向、拖动分隔条、折叠两侧栏）后重新适应 |
| 设计版本标记 | 新增 / 修改的节点描边并带角标，「△N」表示涉及变更数；含新增 / 修改关系的边加底色 |
| 舞台 | 运行视角下布局不变；`stageDisplay(视图, 参与节点, 叠加, 显示方式, 临时对象)` 给出每个节点与边是显示、淡化还是隐藏（V5）：参与节点取时序模型的泳道（本层全部分支的帧端点），只在未选分支 / 未到达处出现的淡化；回放边（走过、当前、预览、悬停预览、经由上层、未建模）始终显示；其余节点与静态边按显示方式隐藏 / 淡化 / 照常（V8）；「在画布上显示」的对象（V9）的静态边及对端节点照常显示；悬停的可见节点（V10）在「隐藏」模式下它的静态边及对端节点淡显、在「淡显」模式下它的静态边照常；带与边界框始终显示。画布左下角（缩放按钮旁）切换显示方式。舞台视图补齐场景端点（P12），不受显示开关影响（L9） |
| 选中突出 | 只在选中步骤时（`emphasis.selected` 不为空，R15）：选中消息与配对消息（R16）所在的边与端点照常，其余走过的边与步骤序号淡为灰色；选中其他对象或场景时不变灰。舞台本身（走过的边、当前消息流动）始终按进度 |
| 回放叠加 | 数据来自 Layout 的 `stageOverlay`。当前可见消息的边沿步骤方向流动（可与箭头相反，P10）——画法为强调色加粗底线上走一串浅色短点，与边本身的类型色、粗细无关都看得出流动，图例同款；端点节点为活动态；走过的边保留并标步骤序号（不加粗）；内部活动只高亮节点；落在核心跨层边上时临时显示该边（P7）；经过的边界边显示；本层无对应视图边时按步骤自身的关系绑定画临时线，不参与布局：已绑定关系（关系建在上层）画按关系类型着色的虚线、标「经由上层」（P15），没有绑定任何关系画红色「结构中未建模」虚线（P11），一条可见消息中混有两种帧时按未建模（P16）；停在分支点时各选项首条消息的边以虚线预览并标选项序号；当前帧本层不可见时提示并可跳到能看到它的层次（R11）；悬停时序图消息时预览其落点 |
| 代码事实 | 结构视角开启「代码事实」时（缺省开启，K9、Y4、Y5，`desk.facts.level`）：只标异常——已证实的关系边照常（实线、不标），未证实与部分证实的画虚线并在标签末尾加 ?；含违规的视图边加红晕（边界边因此也出现；同方向多条时只标关系类型声明顺序中的第一条）；未描述依赖与基线外的违规（已知与已豁免的不画）画成代码依赖叠加线（坐标 `linkRoute`，不参与布局）——点线，有违规为红色、否则为 `--edge-code`，标「未描述 N · 违规 M」，单击选中它（`sel=d:`，K10）；本层环的节点在右上角标「↻ 编号」。运行视角不叠加 |
| 交互 | 单击节点 / 边 → 选中（运行视角同样，V3）；单击「经由上层」临时线 → 选中对应关系，「未建模」临时线不可单击；单击空白 → 取消选中（N13、V4）；双击 → 下钻或跳到边界节点所在层次；悬停 → 高亮相邻；单击步骤序号 → 指向该步（R13）；单击分支预览序号 → 选分支；悬停不弹提示框（W-1） |

## 5. 时序图

只画定位好坐标的时序模型（见[场景投影与回放 §7](./scenario.md#7-时序模型与时序图排布)）：

- **泳道与消息**：参与者头部与生命线；泳道按层次顺序（P9），同一父模块的泳道头上方有分组框标父模块名（P13）；外部参与者在最左，竖线隔出系统边界；同步实线实心箭头、异步虚线开放箭头、显式返回（R2、S10a）；内部活动画成激活条；本层没有对应视图边的消息在标签后标「经由上层关系」（P15）或「结构中未建模」（红色箭头，P11）。
- **组合框**：左上角标类型；`loop` 标条件，`par` 标「并行（串行回放）」，`ref` 显示被引用场景名；`alt` 显示全部分支与条件，已选正常、未选淡化、未到达全部淡化，每个条件是可单击的页签（已选的加下划线）；折叠的框缩成一行（P6）。
- **选中突出**（R15、R16，`emphasisOf`）：选中步骤时只有该消息用选中样式（强调色、底色），配对的调用 / 返回只加浅色「配对」标记，其余消息照常；选中模块、文件、关系、视图边、参与者时 `emphasis.lanes` 中的泳道头（顶部与底部两份）与生命线突出，消息都不用选中样式；选中的不是步骤时，进度所在消息只在序号旁加小标记（▸）。未选分支与未到达的消息保持更淡。
- **交互**：单击消息（含未选分支上的）→ 指向该步（R13）；单击 `alt` 的分支条件 → `chooseBranch`（F6e）；悬停消息时在结构图上预览对应的边；本层看不到任何帧时提示并提供「跳到场景所在层次」（R5）。
- **头尾固定**（D-2）：泳道头（含分组框与系统边界线）固定在顶部，底部另有一份泳道头，消息区夹在中间纵向滚动；三者在同一个滚动容器里，按时序图自身宽度从左起排、不拉伸，横向滚动时一起移动。
- **滚动**（D-7）：只在用户移动进度（单步、指向、拖动进度、回到开头，含改选分支使进度移动）后把进度所在的步骤滚到纵向中间；悬停、选中、切换层次、重新加载都不滚动。副栏标题栏的「定位」把进度所在的步骤滚到中间。
- **无悬停弹出**（W-1）：泳道头、消息、分支条件都不弹提示，信息在属性面板查看。
- **信息条**：没有单独的信息条；当前帧本层不可见的提示（R11）与「定位」在副栏标题栏（§2，ADR-0010）。

## 6. 源代码预览

`source/SourceView.vue`（SR-8、G17）：只读显示预览文件。顶部为路径、归属模块（可定位）、行数；正文为 Shiki 按扩展名高亮的代码与行号（与签名高亮共用 `shared/highlight.ts`，按需加载语法；不认识的扩展名、超过 20 万字符的文件显示纯文本，仍带行号）。过大、二进制、文件不存在、源码清单读取失败（G1）时给提示。没有编辑、保存、跳转定义等 IDE 功能。

## 7. 回放控制条

上一步 / 下一步（按本层可见消息，R7）、进度条拖动到已走路径上的任意位置；显示「第 i / N 步」，停在开头时 i 为 0，分支点之后未定时为「≥ N」（F6d）。**路线总览**（F6f）：`routeOf` 给出的分支点依次显示为「序号 · 所选条件 ▾」，下拉列出全部条件，改选即 `chooseBranch`；待选的分支点显示「待选」；改选丢弃了其后的选择时，在路线旁提示「已重置其后 n 个分支选择」数秒。到达分支点时另外展开全部选项（条件 + 首条消息）供选择，未选时「下一步」不可用。不提供自动播放（R1）。键盘：← → 单步，数字键选分支。

## 8. 属性面板

按**选中**分派（V2）：结构视角为选中的对象，无选中时为当前父模块（根层为系统）；运行视角选中步骤时为步骤面板，选中场景（进度在开头且没有选中其他对象）时为场景面板，选中其他对象时为该对象的面板（运行信息在上）。

| 面板 | 内容 |
|---|---|
| 系统 | 顺序：健康度（`GovernanceSection part="summary"`：事实统计、违规与环度相对基线）→ 分层（或顶层模块）→ 简介 → 生成来源与规模 → 治理明细（`part="detail"`：违规分组、模块环、外部依赖、拦截记录）；提交版本时顶部为提交面板（提交说明与变更清单）；设计版本时顶部为设计面板：设计目标、本轮说明、待确认问题、按实体分组的变更清单（可跳转，删除项只列出）、各轮评审意见与轮次切换 |

| 关系 | 两端、类型；「关系」一节按五个维度各一行：控制流、知识（由代码事实给出：同向 / 反向 / 经端口 / 不判定）、语义、同步性、平面（ADR-0022）；说明、经由接口、数据结构、代码事实；不在当前视图时「定位到所在层次」 |
| 聚合边 | 关系类型、条数、同步 / 异步汇总；原始关系，可逐条定位 |
| 参与者 | 名称、类别、说明、入口关系、由它触发的场景 |
| 文件 | 路径；行数与是否超长（G21）；归属模块（可定位，冲突时全部列出并标「归属冲突」）或「未归属」（提示补 `codeRefs` 或写进忽略清单）/「已忽略」；是哪些模块的入口；当前层次中的投影说明（G14）；导出（名称、类别、签名，对应到接口的标出接口）；「预览源码」（重新打开副栏预览） |
| 代码依赖（选中叠加线时） | 两端；其中的违规（规则、理由、已知 / 新增 / 已豁免、文件证据）；投影到这对节点的模块依赖（已描述 / 未描述、文件证据，文件可单击选中）；这对节点在本层已不存在时说明原因（K10） |
| 场景（选中场景时） | 说明、触发者与原因、场景所在层次（可跳转）、参与模块、ref 的引用与被引用；步骤目录见导航树的步骤树（§9） |
| 步骤（选中步骤时） | 头部：序号、标签、类型、所在组合框与分支条件。依次：**作用**（标签与说明）；**输入**（本步携带的数据）；**输出**（配对返回的数据与标签，可指向该返回；本步就是返回时为「回应」配对的调用；异步为「不等待返回」；没有显式返回时为「隐含返回，见接口签名」，F7）；数据结构（可展开）；经由接口；真实端点与本层投影（经由上层关系时注明「对应关系建在上层」并给出该关系，可「定位」到它所在的层次，P15）；本层一条可见消息覆盖多帧时列出这些帧；**结构关系**（默认折叠：对应关系，推断时标「推断」；「在画布上显示」，V9）；出处 |

- **架构治理**（GV-7，`GovernanceSection.vue`、`ModuleGovernance.vue`、`RelationFact.vue`）：系统面板为事实统计（文件 / 模块依赖、关系证实、未描述依赖；违规与环度相对基线——违规 ±N、环度 ↑ / ↓ / 持平，绝对值在悬停中，无基线时为绝对数；模块环个数与最大规模；基线）、违规按新增 / 违规（无基线）/ 已知 / 已豁免分组（展开见理由与文件证据）、模块环、外部依赖、拦截记录摘要；模块面板为生效的规则、出入的违规与未描述依赖、所在的模块环，以及选中节点带环编号时「所在的本层环 ↻N」（GV-9、Y5）：环内节点、构成环的每条本层依赖 A → B（展开见投影前的模块依赖与文件证据），单击一条即选中对应的视图边或代码依赖，画布随之高亮；关系面板为证实状态与文件证据（写了 `via` 的标「不判定：经 HTTP」等，头部标「经 …」，K5b；未证实分三档：编译期关系、运行时关系两端无任何依赖——这两档标红并提示按代码修正描述；运行时关系只有反向或经组装的依赖——灰字「可能经端口或注入」，K6）；关系行后标 ✓ / ?。没有代码事实时系统面板说明原因（K8）。
- **运行信息**（V6，`RunSection.vue`）：运行视角下模块、关系、聚合边、参与者面板顶部的一节（文件面板没有运行信息）——本场景中参与的步骤（可指向，标出离进度最近的一步）、在本层收发的消息、用到的接口与数据；面板原有的结构信息折叠在其下方；模块与参与者另有「在画布上显示结构关系」（V9）。没有「已钉住」之类的提示：选中就是选中（ADR-0012）。
- **设计版本标记**：标题处的新增 / 修改标记与「改了哪些字段」；`designNote` 显示为「设计说明」。
- **内容组件**：Markdown（禁用原始 HTML）、TS 代码高亮（按需加载 Shiki）、接口与数据结构折叠项、关系行、分节。

## 9. 导航树

左侧固定栏（W-7，`tree/**`），四个页签：「模块」「文件」「问题」始终可用，「步骤」只在运行视角出现；进入运行视角切到「步骤」，退出切回「模块」，选中文件切到「文件」，单击画布的问题角标切到「问题」（T1）。页签由项目视图持有（注入键 `NAV_TAB`，`shared/navTab.ts`），与展开状态、宽度一样只属于这块界面，不进视图状态与 URL。

| 页签 | 内容 | 同步（状态 → 树） | 操作（树 → 意图） |
|---|---|---|---|
| 模块 | 系统为根的模块树，层按 `order`；目标态模块虚线标记；结构视角下「只看现状」开启时不列目标态模块（T2） | 当前层次的祖先链展开并标出当前层次；选中的模块高亮、展开到它并滚到可见（T3）；选中文件时归属模块标出并展开到它（G14）；运行视角下标出参与模块（`scenarioModules`）与当前步骤的两端（T5） | 单击 → `revealModule`（N4），系统 → `goTo(根)`；双击有子模块的 → `drillInto`；悬停本层可见的模块 → `setHover`（T3、T4） |
| 文件 | 目录树 `fileTree`：目录可折叠并显示文件数、未归属数、行数合计与超长数（G21）；文件行显示行数，超长标红；文件行标出未归属（警告色）、归属冲突、已忽略（灰），内部文件全部忽略的目录同样标灰（G18）；顶部为源码根目录、「只看未归属」「只看超长」筛选与「刷新」；源码清单读取失败时只显示原因（G1） | 选中模块（含层）：其文件高亮，所在目录标点；展开的目录恰为含高亮文件的目录，其余收起，滚到第一个文件（G13）；选中文件：该行高亮；选中文件、步骤、边等其他对象时树的展开与滚动不动（G13） | 单击文件 → `select({ kind: 'file' })`（G16）；单击目录 → 展开 / 折叠 |
| 步骤 | 步骤大纲 `outlineScenario`：组合框（`loop`、`par` 分支、`ref`）为可折叠的分组，`alt` 列出全部分支与条件，空分支占位，帧显示「A → B：标签」（T6） | 帧标出已走过 / 进度所在 / 未走到 / 未选分支 / 未到达；选中步骤时它的帧用选中样式，同一条可见消息的其他帧用浅一级的「同一步」样式并注明「本层合并为 1 步」；选中的不是步骤时进度所在的帧只加小标记；本层可见的帧显示可见消息序号，不可见的标「本层不可见」；进度所在的帧滚到可见（T7） | 单击帧 → `seek`（R13）；单击 `alt` 分支标题 → `chooseBranch`（F6b）；悬停帧 → 在结构图上预览落点（同时序图）（T8） |
| 问题 | 返工清单 `desk.rework`（Q7、Q8）：顶部按严重度筛选（全部 / 错误 / 提醒 / 提示，带计数）与「复制全部给 agent」；每条一行（严重度、标题、类别与规则编号、受影响处数），展开见说明、根因所在（描述文件:行）、受影响位置（最多 50 处）、建议动作与 YAML 片段；没有代码事实时注明未含事实类问题 | 描述重新加载、源码或代码事实就绪后重算；页签计数为错误与提醒 | 单击行 → 展开 / 收起；单击受影响的源码文件 → `selectFile`；「定位」→ 关系 `revealRelation`、文件 `selectFile`、否则第一个模块 `revealModule`；「复制给 agent」→ `desk.reworkPrompt(item)` 写剪贴板（Q9） |
