# 专题：工作台界面

> 回答：页面怎么布置、每个组件画什么、交互意图怎么上交。
> 覆盖模块：呈现层全部。呈现层只读视图状态的派生数据、只调 DeskState 的操作，不做投影、布局与规则计算（[03-architecture.md §3.5](../03-architecture.md#35-模块边界的判据)）。界面行为对应的规则见 [02-domain.md](../02-domain.md)，需求编号见 [01-requirements.md](../01-requirements.md)。

## 1. 页面与路由

| 路由 | 页面 | 说明 |
|---|---|---|
| `/` | 项目列表 | 读 `projects.json`；每个项目一张卡片，卡片下列出推进中的设计版本（打开最新一轮），已归档的只注明个数（DV-6）；任一项目描述变化后刷新 |

## 2. 项目视图布局

两部分（LY-1，ADR-0064；信息组织参照 Claude Code，CLAUDE.md §2 第 10 条）——**状态：待实现（第二十二轮）**；波 1 只换了视图状态层，呈现层仍是旧的三列版式（导航浮层、属性抽屉、资料区），经适配器显示新的工作区状态：

```text
┌ 项目 ▾ ─────┐┌ ▯ 根层 › 视图状态层   [结构|交互] 场景 ▾  显示 ▾ ⌕ ▯ ┐┌ 视图状态层 › DeskState  state.desk  核心 ‹ ┐ ← 三区页头 44px，底线一条线（LY-2）
├─────────────┤├─────────────────────────────────────────────────────┤├─────────────────────────────────────────────┤
│ 模块 场景 改动 ││ ⚠ N 描述落后 N 个提交（画布左上角）        图例 ▾      ││ 图解 · 描述 · 核对 · +                       │ ← 上组
│ ▾ 系统       ││                                                     ││  （主语 × 标签类型 的投影）                   │
│   ▸ 呈现层   ││                       画  布                         │├═════════════ 拖拽分隔 ═════════════════════┤
│   ▾ 状态层   ││                                                     ││ 时序图 · 对话 （下组，可无）                   │
│             ││ ＋ − 适应                 ◀ 第 3/21 步 ▶（回放胶囊）   ││                                             │
└─────────────┘└─────────────────────────────────────────────────────┘└─────────────────────────────────────────────┘
   侧栏（可收起）                     画布                                          视图区（可收起）
 └──────────────── 系统：主语在这里决定 ────────────────────────────┘└──────────── 视图：主语的投影 ───────────────┘
```

- **侧栏**（LY-3、LY-4）：停靠在最左，页头是项目标题（项目菜单，TB-6 修订）；三页——模块（树，根行 = 系统）、场景（列表）、改动（草图编辑时）。可收起、可拖宽（200–400，缺省 240），开关与宽度按本机记住（LY-10b、`sync/workspaceMemory.ts`）；没有记忆时窗口宽 ≥ 1440 缺省展开。只由人开合。
- **画布页头**（LY-5）：侧栏开关、面包屑、视角段「结构 ｜ 交互」、场景胶囊（「场景 ▾」/「场景名 ✕」）、显示 ▾、⌕（⌘K）、视图区开关。
- **视图区**（LY-7–LY-12）：页头是主语条（一行：路径 › 名称、ID、角色徽标；LY-7、LY-7a），其下至多上下两组标签。视图标签（图解、描述、核对、时序图）按类型各一个、内容随主语变；资料标签（对话、源代码、设计说明、ADR）不跟随。图解常驻、有场景时时序图常驻（可拖不可关）；描述、核对可关、从「+」再开；标签可拖到另一组或组内换序，拖到下半区开下组，一组拖空即合并；分隔可拖。缺省排布由情境推出（LY-11），人改过的按情境记在本机；视图区可整体收起，收起时画布右上角出「视图 · 主语名 ›」（LY-12）。
- **选中不改变宽度**：侧栏、画布、视图区只由人拖动或开合，选中、打开场景、打开资料都不改宽度（I3，LY-16）。
- 设计信息条（F-60–F-63）在非当前版本时出现在画布页头之下。

- **画布标题行**（TB-7–TB-9，`CanvasTitle.vue`）：模型画布左上角一排（第二十二轮：面包屑移入画布页头，LY-5，待实现）——面包屑「根层 / … / 当前层次」、⚠ 问题胶囊（单击切到「问题」页签，W-6）、源码胶囊（`source/SourceDeltaChip.vue`：「描述落后 N 个提交」，单击展开原文，落后超过 100 个、提交不在源码树中、源码不可用时警示色，G22）、非当前版本时的版本胶囊（× 回当前版本）。草图画布下不出现。
- **视图标签的内容**（LY-13，波 3 实现；在此之前沿用旧组件）：
  - **图解**（EX-1–EX-7，ADR-0055，`dock/ExplainerDoc.vue`、`dock/explainerFrame.ts`）：主语是系统或模块且有图解时显示它，其他主语给两端或所属的链接；依据过期时标签后加「基于旧描述 · N 处改动」。内容区顶部一行是 ↑ ↓（EX-4）与过期提示；下面是沙箱 iframe——只给 `allow-scripts`，`srcdoc` 由 `explainerSrcdoc` 组装：head 最前注入禁止网络请求的 CSP 与引用样式，body 末尾注入桥接脚本，按 `desk.explainers.refs` 给的原文填 `data-field`、把单击变成 `postMessage`。父页只接受**来源是这个 iframe 窗口**、形状正确的消息：`arch:select` 即选中（LY-15，视图随主语跟随）。
  - **描述**：架构台从描述渲染的事实（原事实卡、五问卡、关系 / 端口 / 参与者 / 环 / 层面板；回放中为步骤详情与运行信息，V6）。
  - **核对**：核对卡（PC-6–PC-13，ADR-0059）。
  - **时序图**（§5）：内容区顶部一行（WS-10）：本层不可见提示与「到能看到它的层次」（R11）、「定位」（`centerCurrent`）、「图例」（时序图箭头约定浮层，ADR-0017）。
- **资料标签**：源代码（§6；选中文件或单击「预览」打开为预览标签，LY-8a）、对话（DA-1）、设计说明（DL-10）、ADR。新资料进上组（LY-10a）。

- **舞台显示**（V8、V9，`stage/useStageDisplay.ts`）：交互关系显示方式（按项目记在本地）与「在画布上显示」的临时对象只属于画布这块界面，由项目视图创建并注入，画布读取、面板写入；进度、选中、层次任一变化即清除临时对象。

## 4. 画布

画什么由 Layout 的纯函数 `canvasScene(input)`（`src/layout/canvas.ts`，ADR-0013）算出：输入为带坐标的层次视图、模型索引、选中与悬停、舞台叠加与显示方式、选中突出、设计版本差异、文件高亮；输出为节点与边（位置、类型、数据、类名、层级）以及适应画布用的可见节点。下表各行描述的就是它的规则。GraphCanvas 只把结果直接写入 Vue Flow 的 store（属性同步在「上一层有选中、切回总览」时会被跳过）、把交互转成操作、适应画布。

| 方面 | 做法 |
|---|---|
| 节点 | 模块（职责摘要、可下钻标识、目标态虚线）、边界节点（外部模块与所在路径）、带（层名、抽象原则、可依赖层）、核心模块、共用件架（`SharedNode` 紧凑块，框 / 带内「共用件」字样；运行视角淡化、当前步骤经过的高亮，P18）与「共用 ×N」角标（`DiffMark`，悬停或选中节点时画它与共用件之间的曲线，O10）、本层框「共用件 N · 折叠 M」计数（父模块框右上角、带右上角，O11；本层有共用件或折叠时普通层次也画父模块框）、`+N` 占位（普通层次同样，O8，双击无动作；单击临时展开为该层全部模块、变为「收起 N 个」，O6；z 序在核心跨层边之上）、普通层次没有核心而普通模块超过七个时画布右上角提示「N 个模块，考虑标出核心」、普通层次的核心模块大块（`ModuleNode.core`）；带宽按画布宽度铺开（画布以 ResizeObserver 把宽度交给 `desk.setCanvasWidth`，换算成带内列数，O7）；参与者节点（按类别图标：用户在系统框上方、外部系统与时间在右侧，A7）与边界框（根层为系统框；下钻后外框为系统、内框为当前父模块，边界节点在两框之间，`FrameNode`）；运行视角下的步骤序号与分支预览序号（小节点，单击指向 / 选分支） |
| 边 | 按走线画折线或曲线：普通层次全部正交折线（端口上进下出，L11；边界边显示时才按需走线，L4；画出来的框外边各占一条轨道、标签不相碰；同一侧左动右静——动态关系的出入点在左半、静态在右半），交叉处水平段起半圆小桥（跳线）；曲线只用于分层总览相邻两层间的核心跨层边与参与者的边、回放临时线与代码依赖叠加线（跨多层的核心跨层边走核心车道、是折线，O3b）。同一对节点之间按关系类型各一条（L5），平行的曲线按序号错开。层级：与聚焦对象相邻、选中、回放经过的边浮在节点之上（`EDGE_Z`），其余在模块节点之下；步骤徽标、分支预览与「+N」占位块再高一档。编码一个通道一个维度（L10、ADR-0018）：颜色 = 关系类型（`--rel-*`，运行时饱和、`implements` 低饱和且更细；`depends` 随 ADR-0026 去掉）；线型 = 事实状态（实线 / 未证实虚线 / 叠加线点线，K9）；箭头 = 同步实心、异步空心「V」、`implements` 空心三角（`ArrowMarker`，`RouteEdge` 与图例的 `LineSwatch` 共用；大小随线宽档 `arrowSize`，线按 `retractEnd` 回缩一个箭头深度，颜色跟随线色）；线宽 = 聚合条数三档（`RouteEdgeData.weight`）；标签只有聚合边的 `×N`（带边框 pill）与异常标记，不写类型名——elk 为每条直接边申请至少 24×18 的标签槽，没给出可用坐标时画布按走线中点放（`routeMidpoint`）；平行边终点重合时在目标节点边缘错开（`spreadEnds`）；选中为强调色窄晕（线宽不变）；违规红晕优先于设计变更底色 |
| 文件高亮 | 选中文件时，`fileNodes` 给出的节点加文件高亮描边（G14）；归属模块是当前层次本身时不高亮，提示在文件面板 |
| 聚焦与变淡 | 结构 / 交互视角：选中给一跳底，悬停在其上叠加一跳（L27，ADR-0037）——与选中或悬停的节点都不相邻的节点和边变淡；结构视角的影响面查询（K15b）生效时以闭包代替选中的一跳，悬停照常叠加；分层总览里带不参与变淡；核心跨层边只在聚焦核心模块时出现（O4）；边界边只在聚焦其一端或被选中时出现（L4）。运行视角由舞台显示与选中突出决定（下两行） |
| 适应画布 | 内容外框取自布局结果，运行视角隐藏静态内容时只取可见节点；切换层次、切换显示方式、画布容器尺寸变化（进入运行视角、切换分屏方向、拖动分隔条、折叠两侧栏）后重新适应。首次适应（WS-3）：画布先不可见（`.canvas.unrevealed`：透明、不接收指针——Vue Flow 给节点内联 `visibility: visible`，不能用 visibility），逐帧探测——布局同步没有进行中的请求（`desk.layoutPending`）、代码事实不在读取中、Vue Flow 的尺寸已与容器实测一致、尺寸与 `CANVAS_INSET` 连续两帧不变——满足后适应一次再显示；4 秒兜底照常显示。显示前其他适应触发都不动作 |
| 设计版本标记 | 新增 / 修改的节点描边并带角标，「△N」表示涉及变更数；含新增 / 修改关系的边加底色 |
| 舞台 | 运行视角下布局不变；`stageDisplay(视图, 参与节点, 叠加, 显示方式, 临时对象)` 给出每个节点与边是显示、淡化还是隐藏（V5）：参与节点取时序模型的泳道（本层全部分支的帧端点），只在未选分支 / 未到达处出现的淡化；回放边（走过、当前、预览、悬停预览、经由上层、未建模）始终显示；其余节点与交互边按显示方式隐藏 / 淡化 / 照常（V8）；「在画布上显示」的对象（V9）的交互边及对端节点照常显示；悬停的可见节点（V10）在「隐藏」模式下它的交互边及对端节点淡显、在「淡显」模式下它的交互边照常；带与边界框始终显示。画布左下角（缩放按钮旁）切换显示方式。舞台视图补齐场景端点（P12），不受显示开关影响（L9） |
| 选中突出 | 只在选中步骤时（`emphasis.selected` 不为空，R15）：选中消息与配对消息（R16）所在的边与端点照常，其余走过的边与步骤序号淡为灰色；选中其他对象或场景时不变灰。舞台本身（走过的边、当前消息流动）始终按进度 |
| 回放叠加 | 数据来自 Layout 的 `stageOverlay`。当前可见消息的边沿步骤方向流动（可与箭头相反，P10）——画法为强调色加粗底线上走一串浅色短点，与边本身的类型色、粗细无关都看得出流动，图例同款；端点节点为活动态；走过的边保留并标步骤序号（不加粗）；内部活动只高亮节点；落在核心跨层边上时临时显示该边（P7）；经过的边界边显示；本层无对应视图边时按步骤自身的关系绑定画临时线，不参与布局：已绑定关系（关系建在上层）画按关系类型着色的虚线、标「经由上层」（P15），没有绑定任何关系画红色「交互中未建模」虚线（P11），一条可见消息中混有两种帧时按未建模（P16）；停在分支点时各选项首条消息的边以虚线预览并标选项序号；当前帧本层不可见时提示并可跳到能看到它的层次（R11）；悬停时序图消息时预览其落点 |
| 演化 | 结构 / 交互视角开启「演化」组的热度或时间耦合时（缺省关闭，J5，`desk.evolution.level`）：热度为节点右下角三档色块角标（模块、核心模块、边界节点、带），修改 / 缺陷二选一；时间耦合为本层两端之间的灰色波浪线（`temp: 'couple'`，坐标 `linkRoute`，不参与布局）标 `×N`，无依赖无关系的更深色；单击耦合线即选中它（`sel=c:`，J7）；运行视角不叠加 |
| 代码事实 | 交互视角开启「代码事实」时（只适用于交互视角）（缺省开启，K9、Y4、Y5，`desk.facts.level`）：只标异常，一律写在标签位（L26，`layout/labels.ts` 的 composePill 组装：异常段警示色在前、机制等修饰段中性在后，ADR-0041）、不改线型——已证实的关系边不标，未证实与部分证实的标「未证实」（聚合边带条数，分层总览只写在聚合边上）；含违规的视图边加红晕并标「违规」（边界边因此也出现；同方向多条时只标关系类型声明顺序中的第一条）；未解释的交互（K7，原名未描述依赖；ADR-0026 口径）与基线外的违规（已知与已豁免的不画）画成代码依赖叠加线（坐标 `linkRoute`，不参与布局）——虚线（依赖，L18），有违规为红色、否则为 `--edge-code`，标「违规 M · 未解释 N」，单击选中它（`sel=d:`，K10）；本层环的节点在右上角标「↻ 编号」。运行视角不叠加 |

## 5. 时序图

只画定位好坐标的时序模型（见[场景投影与回放 §7](./scenario.md#7-时序模型与时序图排布)）：

- **泳道与消息**：参与者头部与生命线；泳道按层次顺序（P9），同一父模块的泳道头上方有分组框标父模块名（P13）；外部参与者在最左，竖线隔出系统边界；同步实线实心箭头、异步虚线开放箭头、显式返回（R2、S10a）；内部活动画成激活条；本层没有对应视图边的消息在标签后标「经由上层关系」（P15）或「交互中未建模」（红色箭头，P11）；有代码事实时，无证据的消息在标签后加「?」（S17）。
- **组合框**：左上角标类型；`loop` 标条件，`par` 标「并行（串行回放）」，`ref` 显示被引用场景名；`alt` 显示全部分支与条件，已选正常、未选淡化、未到达全部淡化，每个条件是可单击的页签（已选的加下划线）；折叠的框缩成一行（P6）。
- **选中突出**（R15、R16，`emphasisOf`）：选中步骤时只有该消息用选中样式（强调色、底色），配对的调用 / 返回只加浅色「配对」标记，其余消息照常；选中模块、文件、关系、视图边、参与者时 `emphasis.lanes` 中的泳道头（顶部与底部两份）与生命线突出，消息都不用选中样式；选中的不是步骤时，进度所在消息只在序号旁加小标记（▸）。未选分支与未到达的消息保持更淡。
- **交互**：单击消息（含未选分支上的）→ 指向该步（R13）；单击 `alt` 的分支条件 → `chooseBranch`（F6e）；悬停消息时在交互图上预览对应的边；本层看不到任何帧时提示并提供「跳到场景所在层次」（R5）。
- **头尾固定**（D-2）：泳道头（含分组框与系统边界线）固定在顶部，底部另有一份泳道头，消息区夹在中间纵向滚动；三者在同一个滚动容器里，按时序图自身宽度从左起排、不拉伸，横向滚动时一起移动。
- **滚动**（D-7）：只在用户移动进度（单步、指向、拖动进度、回到开头，含改选分支使进度移动）后把进度所在的步骤滚到纵向中间；悬停、选中、切换层次、重新加载都不滚动。时序图标签顶部的「定位」把进度所在的步骤滚到中间。
- **无悬停弹出**（W-1）：泳道头、消息、分支条件都不弹提示，信息在属性面板查看。
- **信息条**：没有单独的信息条；当前帧本层不可见的提示（R11）、「定位」「图例」在时序图标签内容区顶部（§2，WS-10，ADR-0054）。

## 6. 源代码预览

`source/SourceView.vue`（SR-8、G17）：只读显示预览文件。顶部为路径、归属模块（可定位）、行数；正文为 Shiki 按扩展名高亮的代码与行号（与签名高亮共用 `shared/highlight.ts`，按需加载语法；不认识的扩展名、超过 20 万字符的文件显示纯文本，仍带行号）。过大、二进制、文件不存在、源码清单读取失败（G1）时给提示。带目标行打开时（`OPEN_PREVIEW(path, line)`，步骤面板的候选调用点）滚到该行并标出（S18）。没有编辑、保存、跳转定义等 IDE 功能。

## 7. 回放胶囊

`PlayerBar.vue`（CD-7–CD-9，ADR-0057；取代贯穿整行的回放控制条，回放控制不进时序图，D5）：运行视角下浮在画布底部的一枚胶囊 `◀ 第 n / ≥N 步 ▶ ━●━ 路线 ▾`，与左下角的缩放胶囊同一行、同一卡片样式（`.desk-pill`）。位置由项目视图按 `shared/playerPlacement.ts` 推出（CD-8）：居中于未被悬浮卡片盖住的画布（`--canvas-inset`），与缩放胶囊相碰时右移让开；这样仍放不下时居中于整个画布、悬浮卡片列底部让出胶囊（`.player-bar.wide`）。

上一步 / 下一步（按本层可见消息，R7）、进度条拖动到已走路径上的任意位置；显示「第 i / N 步」，停在开头时 i 为 0，分支点之后未定时为「≥ N」（F6d）。**路线**（CD-9）：胶囊上只显示编号「路线 a·b」（各分支点所选选项的序号），停在未选的分支点时为警示色的「选路线 ▾」；单击展开胶囊上方的浮层，里面是分支选择（`BranchChooser`）与路线总览（`RouteBar`）；停在一个新的分支点时浮层自动展开。**路线总览**（F6f）：`routeOf` 给出的分支点依次显示为「序号 · 所选条件 ▾」，下拉列出全部条件，改选即 `chooseBranch`；待选的分支点显示「待选」；改选丢弃了其后的选择时，在路线旁提示「已重置其后 n 个分支选择」数秒。到达分支点时浮层里展开全部选项（条件 + 首条消息）供选择，未选时「下一步」不可用。不提供自动播放（R1）。键盘：← → 单步，数字键选分支；时序图上单击某一步即跳到那一步（CD-10，写进帮助）。

## 12. 草图画布（ADR-0025）

> 状态：已实现（子树间关系的浅色只读聚合线后续）。二期叠在分层总览上的编辑态（ADR-0024：`edit/canvas/**`、`edit/panel/**`、`edit/EditBar.vue`）已移除。

草图是思考的介质：一张草图挂在一个模块下、只画一个层次（X9）。打开草图即进入**草图画布**——独立于模型画布，不复用 `canvasScene` 与 elk 布局，模型画布上没有编辑态（X7）。画布与面板只发编辑操作；位置是草图自己的 `layout`，只在初始与「重新排列」时自动布局（X15）。
