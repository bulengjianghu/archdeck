# 专题：工作台界面

> 回答：页面怎么布置、每个组件画什么、交互意图怎么上交。
> 覆盖模块：呈现层全部。呈现层只读视图状态的派生数据、只调 DeskState 的操作，不做投影、布局与规则计算（[03-architecture.md §3.5](../03-architecture.md#35-模块边界的判据)）。界面行为对应的规则见 [02-domain.md](../02-domain.md)，需求编号见 [01-requirements.md](../01-requirements.md)。

## 1. 页面与路由

| 路由 | 页面 | 说明 |
|---|---|---|
| `/` | 项目列表 | 读 `projects.json`；每个项目一张卡片，卡片下列出设计版本（打开最新一轮）；任一项目描述变化后刷新 |
| `/p/<项目>` | 项目视图（当前版本） | 按项目 + 版本创建并注入 DeskState |
| `/p/<项目>/d/<设计>/<轮次>` | 项目视图（设计版本） | 同上 |

切换项目或版本时重建项目视图，每个项目的每个版本一份独立状态；查询参数见[视图状态与协调 §3](./view-state.md#3-会话规则视图状态转移)。

## 2. 项目视图布局

```text
┌ 顶部栏：版本切换 · 视角切换（待实现） · 面包屑 · 搜索 · 显示开关 · 面板折叠 ┐
├ 设计信息条（仅设计版本）                                                 ┤
├ 画布区（分屏容器）                                    │ 分隔条 │ 属性面板 ┤
│   上：结构图（画布）                                  │        │          │
│   下：时序图（运行视角，待实现）                        │        │          │
├ 回放控制条（运行视角，待实现）                                           ┘
```

- 面板宽度可拖动、可折叠，宽度记在本地。
- **分屏容器**（待实现，W-4）：按可序列化的布局树 `PaneLayout` 排布视图，视图组件只按槽位（`structure` / `sequence`）挂载，不知道自己的位置。二期只提供「上下两块、比例可拖、下方可收起」；比例按项目记在本地，不进视图状态与 URL。以后的自由拖拽只扩展布局树的编辑操作。

```ts
type PaneLayout =
  | { kind: 'pane'; slot: 'structure' | 'sequence'; collapsed?: boolean }
  | { kind: 'split'; dir: 'row' | 'column'; sizes: number[]; children: PaneLayout[] }
```

## 3. 顶部栏与信息条

| 组件 | 内容 |
|---|---|

| 视角切换（待实现） | 「结构 ｜ 运行：<场景名>」；结构视角下「运行」弹出场景列表；运行视角下可换场景或退出（V1） |
| 场景列表（待实现） | 默认只列与当前层次相关的场景，可切到全部、按发起者筛选；显示名称、触发者、消息数（R4、R4a） |
| 面包屑 | 「项目 / 系统 / … / 当前层次」，点击任一级返回 |
| 工具栏 | 搜索模块名或 ID 并跳转（N4）；边界节点、只看现状、关系类型筛选开关 |
| 设计信息条 | 设计名、轮次、状态、日期；「设计说明与变更清单」入口；对比基线（当前版本 / 上一轮）；新增 / 修改 / 删除计数；标出变更开关；基线漂移提示 |

## 4. 画布（结构图）

把带坐标的层次视图转成 Vue Flow 节点与边，直接写入其 store（属性同步在「上一层有选中、切回总览」时会被跳过）。

| 方面 | 做法 |
|---|---|
| 节点 | 模块（职责摘要、可下钻标识、目标态虚线）、边界节点（外部模块与所在路径）、带（层名、抽象原则、可依赖层）、核心模块、`+N` 占位；参与者节点与系统边界框（待实现） |
| 边 | 按走线画折线或曲线；颜色按关系类型，线宽随聚合条数增加，异步为点划线 |
| 聚焦与变淡 | 焦点为悬停优先、其次选中；与焦点不相邻的节点和边变淡；分层总览里带不参与变淡；核心跨层边只在聚焦核心模块时出现（O4）；边界边只在聚焦其一端或被选中时出现（L4） |
| 适应画布 | 内容外框取自布局结果，切换层次后适应 |
| 设计版本标记 | 新增 / 修改的节点描边并带角标，「△N」表示涉及变更数；含新增 / 修改关系的边加底色 |
| 舞台（待实现） | 运行视角下本层参与的节点与走过的边突出，其余变淡不隐藏，布局不变（V5） |
| 回放叠加（待实现） | 当前可见消息的边沿步骤方向流动（可与箭头相反，P10），端点节点为活动态；走过的边保留淡色并标步骤序号；内部活动只高亮节点；无视图边时画「结构中未建模」临时虚线（P11）；停在分支点时各选项首条消息的边以虚线预览并标选项序号；当前帧本层不可见时提示（R11） |
| 交互 | 单击节点 / 边 → 选中（运行视角下同时暂停并钉住，V3）；单击空白 → 取消选中（N13、V4）；双击 → 下钻或跳到边界节点所在层次；悬停 → 高亮相邻；单击步骤序号 → 指向该步（R13）；单击分支预览序号 → 选分支 |

## 5. 时序图（待实现）

只画定位好坐标的时序模型（见[场景投影与回放 §6](./scenario.md#6-时序模型与时序图排布)）：

- **泳道与消息**：参与者头部与生命线；外部参与者在最左，竖线隔出系统边界；同步实线实心箭头、异步虚线开放箭头、显式返回（R2、S10a）；内部活动画成激活条。
- **组合框**：左上角标类型；`loop` 标条件，`par` 标「并行（串行回放）」，`ref` 显示被引用场景名；`alt` 显示全部分支与条件，已选正常、未选淡化、未到达全部淡化；折叠的框缩成一行（P6）。
- **交互**：单击消息（含未选分支上的）→ 指向该步（R13）；当前消息高亮并滚动到可见；悬停消息时在结构图上预览对应的边，不暂停；本层看不到任何帧时提示并提供「跳到场景所在层次」（R5）。

## 6. 回放控制条（待实现）

上一步 / 下一步（按本层可见消息，R7）、播放 / 暂停（只有这里能恢复播放，V4）、速度 0.5 / 1 / 2（R12）、进度条拖动到已走路径上的任意位置；显示「第 i / N 步」，分支点之后未定时为「≥ N」（F6d）；到达分支点时展开全部选项（条件 + 首条消息）供选择。键盘：← → 单步，空格播放 / 暂停，数字键选分支。

## 7. 属性面板

按**焦点**分派（V2）：结构视角为选中，否则当前父模块（根层为系统）；运行视角钉住时为选中对象，跟随时为当前步骤（未开始时为场景）。

| 面板 | 内容 |
|---|---|
| 系统 | 简介、生成来源、规模、顶层模块；设计版本时顶部为设计面板：设计目标、本轮说明、待确认问题、按实体分组的变更清单（可跳转，删除项只列出）、各轮评审意见与轮次切换 |
| 模块 | 职责、实现原理、对外接口、核心数据结构、子模块、出边 / 入边、代码与文档引用；层另有抽象原则、包含 / 不包含、可依赖的层 |
| 关系 | 两端、类型、同步 / 异步、经由接口、数据结构、说明；不在当前视图时「定位到所在层次」 |
| 聚合边 | 原始关系与各类型条数，可逐条定位 |
| 参与者（待实现） | 名称、类别、说明、入口关系、由它触发的场景 |
| 场景（待实现） | 说明、触发者与原因、场景所在层次（可跳转）、参与模块、步骤目录（按组合框缩进，可指向）、ref 的引用与被引用 |
| 步骤（待实现） | 类型、序号、所在组合框与分支条件；真实端点与本层投影；本层一条可见消息覆盖多帧时列出这些帧；接口、数据结构；对应关系（推断时标「推断」） |

- **运行信息**（待实现，V6）：运行视角下模块、关系、聚合边、参与者面板顶部的一节——本场景中参与的步骤（可指向，标出离播放头最近的一步）、在本层收发的消息、用到的接口与数据；面板原有的结构信息折叠在其下方。
- **设计版本标记**：标题处的新增 / 修改标记与「改了哪些字段」；`designNote` 显示为「设计说明」。
- **内容组件**：Markdown（禁用原始 HTML）、TS 代码高亮（按需加载 Shiki）、接口与数据结构折叠项、关系行、分节。

## 8. 其他

- **问题提示**：列出描述的错误与提醒，展开可见文件与行号（W-6）。
- **图例**：关系类型的颜色与线型、聚合线宽、可下钻与目标态样式；运行视角追加当前步骤、已走过、内部活动、分支预览、未建模、同步 / 异步。
- **键盘**：Esc 先取消选中再返回上级（N9）；Backspace 返回上级，根层回项目列表（N7）。
