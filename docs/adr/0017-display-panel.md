# ADR-0017：画布显示设置与图例合为「显示」面板

- 状态：已采纳（已实现；第十五轮 G13 修订：设置与图例分离为两块、图例行只读、隐藏必留痕，见 [02](../../02-domain.md) L45 与 W-2——第二轮「既是开关又是图例的留在图例组里」由它取代）
- 日期：2026-10-22
- 决策人：项目负责人（第一轮三项、第二轮两项、第三轮一项裁决均按推荐，2026-10-22）
- 关联：需求 W-2、GV-6；领域模型 L8、L9、V8、K9；[workbench.md](../architecture/workbench.md)「显示」面板

## 背景

「画布显示什么、怎么看懂」的控件分在四处：顶部工具栏（边界节点、只看现状、代码事实）、左下角缩放条（运行视角的静态关系显示方式）、右下角图例（关系类型筛选与说明）、设计信息条（对比基线、图上标出变更）。开关和它的说明分开（如代码事实开关在顶部，✓ / ? / 环的说明在图例）；运行视角下顶部三个开关全部置灰，看得见改不了。

## 结论

1. **右下角图例升级为「显示」面板**，可折叠，按「开关与说明放在一起」分组：节点、关系、代码事实（结构视角）、回放（运行视角）。顶部只留导航与窗口类操作（视角、面包屑、搜索、专注、面板），左下角只留缩放。
2. **按视角只出现能用的开关**：运行视角下边界节点、只看现状、关系类型筛选、代码事实不出现，只留一行说明（L9），不再显示一排置灰的开关。静态关系显示方式只在运行视角出现。
3. **代码事实开关收进面板**的「代码事实」分组，不可用时置灰并写明原因（K9）。
4. **折叠时标题后摘要列出非默认设置**（隐藏几类关系、无边界节点、只看现状、代码事实、静态关系非「隐藏」），筛选不会被藏起来；展开 / 折叠按视角记在本机。
5. **不收入**：对比基线、图上标出变更留在设计信息条（属于「看哪个版本」的上下文，只在设计版本出现）；专注、面板、缩放是窗口与视口操作。
6. 面板名为「显示」。

## 第二轮：信息结构与排版（2026-10-22）

第一轮上线后，面板里开关夹在图例中间、一行塞多项导致折行错位、示意大小不一、文字也上了类型色、时序图约定混在画布图例里、面向用户的文字带规则编号。调整为：

1. **先「设置」后「图例」**：设置只放没有图例的开关（边界节点、只看现状；运行视角的静态关系）；既是开关又是图例的（关系类型、代码事实）留在图例组里，代码事实开关放在组标题右侧。
2. **图例按画布上的对象分组**（关系、节点、代码事实、回放），一行一项、左列固定宽示意、右列正文色文字；「线越粗」「点划线」也画成示意，成为正式图例项。
3. **时序图的箭头约定移到副栏时序图标题栏的「图例」浮层**——它解释的是时序图，不是画布（按钮起初为「?」，负责人 2026-10-22 走查认为突兀，改为文字）。
4. **各组可单独折叠，按视角记在本机；运行视角默认只展开「回放」**。
5. 面向用户的文字不出现规则编号，运行视角说明压成一行，完整说法放悬停提示。

## 第三轮：一个通道一组（2026-10-22）

ADR-0018 定了通道分工（颜色 = 类型、线型 = 事实状态、箭头 = 同步 / 异步 / 实现、线宽 = 条数），但「关系」组把五种类型（主体、可筛选）与线型、箭头、线宽说明（修饰）平级排列；「实线 = 已证实」在「关系」与「代码事实」两组重复，代码事实关闭时线型说明仍挂在「关系」组；空心三角与「实现」类型行重复。调整为：

1. **组标题写明通道**：「关系类型 · 颜色」「代码事实 · 线型」。
2. **主体与修饰分开**：类型列表按运行时 / 编译期两段，示意带该类的箭头，可点击筛选；箭头与粗细放进类型列表下方的「线的读法 · 适用于任意类型」浅底卡片，中性色示意、不可点击（负责人选方案 A：卡片在「关系类型」组内，随组折叠，而不另成一组）。
3. **每条规则只讲一次**：线型只在「代码事实」组，关闭时那一组只写「所有关系为实线」；实现的空心三角画在类型行的示意上，读法卡片里只作为箭头的一种并列。

## 取舍

- 开关从一级降到二级，可发现性下降；以默认展开（结构视角）与折叠摘要弥补。
- 运行视角默认收起「节点」「关系」两组，初次使用要多点一下；换来面板高度约减半、不挡舞台。
- 不改分层与状态归属：开关仍在 DeskState 的 toggles，静态关系仍是舞台显示（只在本机，V8）。
