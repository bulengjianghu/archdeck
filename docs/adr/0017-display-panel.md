# ADR-0017：画布显示设置与图例合为「显示」面板

- 状态：已采纳（已实现）
- 日期：2026-10-22
- 决策人：项目负责人（三项裁决均按推荐，2026-10-22）
- 关联：需求 W-2、GV-6；领域模型 L8、L9、V8、K9；[workbench.md](../architecture/workbench.md)「显示」面板

## 背景

「画布显示什么、怎么看懂」的控件分在四处：顶部工具栏（边界节点、只看现状、代码事实）、左下角缩放条（运行视角的静态关系显示方式）、右下角图例（关系类型筛选与说明）、设计信息条（对比基线、图上标出变更）。开关和它的说明分开（如代码事实开关在顶部，✓ / ? / 环的说明在图例）；运行视角下顶部三个开关全部置灰，看得见改不了。

## 结论

1. **右下角图例升级为「显示」面板**，可折叠，按「开关与说明放在一起」分组：节点、关系、代码事实（结构视角）、回放（运行视角）。顶部只留导航与窗口类操作（视角、面包屑、搜索、专注、面板），左下角只留缩放。
2. **按视角只出现能用的开关**：运行视角下边界节点、只看现状、关系类型筛选、代码事实不出现，只留一行说明（L9），不再显示一排置灰的开关。静态关系显示方式只在运行视角出现。
3. **代码事实开关收进面板**的「代码事实」分组，不可用时置灰并写明原因（K9）。
4. **折叠时标题后摘要列出非默认设置**（隐藏几类关系、无边界节点、只看现状、代码事实、静态关系非「隐藏」），筛选不会被藏起来；展开 / 折叠按视角记在本机。
5. **不收入**：对比基线、图上标出变更留在设计信息条（属于「看哪个版本」的上下文，只在设计版本出现）；专注、面板、缩放是窗口与视口操作。
6. 面板名为「显示」。

## 取舍

- 开关从一级降到二级，可发现性下降；以默认展开（结构视角）与折叠摘要弥补。
- 不改分层与状态归属：开关仍在 DeskState 的 toggles，静态关系仍是舞台显示（只在本机，V8）。
