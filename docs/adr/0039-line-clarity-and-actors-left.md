# ADR-0039：线的清晰度——层间间隔按车道撑开、外部参与者在左、几何检查器守住

- 状态：已采纳，已实现（第十二轮 B）
- 日期：2026-10-28
- 决策人：项目负责人（2026-10-28：分层总览层间间隔加大方便走线；外部参与者（外部系统与时间）移到左侧，右侧只留层间关系线；adapter 随之改左；「线多了还是会有重复、看不清，需要整体梳理、依次处理掉」）；起草：第十二轮 r12-lines 会话
- 关联：[ADR-0021](./0021-orthogonal-routing.md)（A7、L11、O3a、O3b 的出处，本 ADR 修订外部系统的方位与空隙里的横段）、[ADR-0030](./0030-boundaries-and-assembly.md)（L14 adapter 的位置，本 ADR 改为左边）、[ADR-0033](./0033-handles.md)（把手角标的文字，标签估宽按它）；规则 A7、L11、L14、O3a、O3b、O11（修订），L30–L33、O14–O16（新增）（02）；需求 C-36（新增）（01）

## 背景

负责人在本项目的分层总览上悬停 DeskState（截图见第十二轮方案）：

1. 两条线进「类型与 Schema」时共线、箭头叠在一起；
2. 模型层上方的空隙里多条核心车道横段只错开 4 px，互相重合并压过带上边的「共用件 0 · 折叠 6」；
3. 右侧通道的把手角标（「×7 · 6 把手」）都落在车道中点，互相压住；
4. 扇入多的节点（DeskState 顶边 14 条）箭头挤成一团；
5. 外部系统在右侧，常被右下的「显示」面板挡住，右侧既有参与者又有层间通道，读不出哪条线是哪类。

这些不是个别层次的毛病：同一套走线在三个项目所有层次上都会出，靠肉眼逐张看既找不全也守不住。

## 裁决

1. **G2 外部在左**（定）：外部系统与时间在系统框左侧（分层总览在层标题栏之外），用户仍在上方，边界节点行（L4）不动；`adapter` 随之贴左边（分层总览里为带内最左一列，紧贴标题栏）。所有层次一致（A7）。右侧只留分层总览的层间关系线（侧边通道、核心车道）。参与者的边从它朝系统框的一侧（右边）进出；带与参与者的边从带的左边进出，上半进、下半出（O16）。
2. **G1 层间间隔按车道撑开**（定，细节推）：带间空隙里每条横段一条轨道（轨距 10、最外一条离带边 18），空隙高度不低于原值 64（O14）。轨道次序让核心车道的竖段不穿过同空隙的别的横段：向上离开的在上（内车道在上）、框外边居中、向下离开的在下（内车道在下）；同车道号的核心边不会同时画出，共用一条轨道（O15）。计数标签挪到带上边框左端（标题栏之上），块的端口短桩与轨道不经过那里（O11）。
3. **W 线的清晰度**：先写几何检查器（测试工具），数五类问题——线段重合（平行、中心距 < 6）、箭头终点重合（< 4）、线压节点或带的文字区、标签互压或压节点、线贴框走（< 6 且并行 > 24）与终点落在框线上；在三个项目所有层次上跑出基线，逐类修，计数作为回归测试只降不升（L30）。修法：
   - 端口放不下时等分压缩，不在边缘堆一点；参与者、边界节点用整条边；核心模块一侧只有进或只有出时用整条边（L31）。
   - 走廊分轨：近到不足一个轨距的平行段也分开；elk 的内部边、常显的线与框线只占不动；挪动后不穿节点；选竖直通道时避开已占的竖段；短桩不伸进对面的节点（L32）。
   - 标签按画布实际写的文字估宽，沿线挑不压节点、文字区与会同时画出的标签的位置（L33）。
   - 相邻两层之间的层间边走块与块之间的竖巷，不与块的端口短桩重合（O15）。

| h5p-arch-desk | 282 → 31 | 92 → 0 | 22 → 3 | 55 → 1 | 23 → 5 | 0 → 0 |
| h5player | 321 → 87 | 49 → 0 | 135 → 0 | 35 → 2 | 61 → 14 | 0 → 0 |
| media-web-player | 179 → 52 | 5 → 0 | 23 → 1 | 17 → 0 | 23 → 7 | 0 → 0 |

口径：分层总览为常显的一组与逐个聚焦核心模块时的一组；普通层次为内部边加全部框外边（运行视角「全显」，框外边最多的情形）。剩下的重合集中在边界节点扇入很大的「全显」（如本项目 `present.panel` 18 条进同一个边界节点）与 elk 把互不相连的节点按 20 px 排开的层次。

## 取舍

- **轨道常留**：空隙按所有可能画出的横段撑开，悬停不改布局（与 O3b 车道常留一致）；代价是核心边多的空隙变高（本项目根层「视图状态层」之下约 120 px）。被否决：悬停时临时撑开——节点跟着跳，违背「选中不跳」（ADR-0036）。
- **几何检查器是测试工具、不进产品**：它回答「改走线有没有变差」，不是给架构师看的信息；计数随描述变化，描述大改时按明细重定上限。
- **标签估宽**：布局时不知道把手数 M，按 M = N 估，偏宽只让标签多让一点。
- **没做**：elk 的组件间距（互不相连的节点间 20 px）与内部边的标签槽宽在 `toElkGraph` 里，本轮归会话 A（按依赖分层）改动；短桩缩短（L32③）先兜住「线伸进节点」。
