# ADR-0006：分屏方向可选、取消自动播放、导航树

- 状态：已采纳
- 日期：2026-10-20
- 决策人：项目负责人（三项方向）；实现者提出的细化规则（来源「议」）列在下文，待负责人确认
- 关联：需求 W-1、W-4、W-7、D-3、D-7、D-10、D-12，验收标准 §6.2、§6.3；领域模型 §2（V、R、F、N、T）；ADR-0003、ADR-0005

## 背景

二期上线后负责人提出三条优化意见：

1. 时序图在结构图下方。PC 屏幕横向空间更宽裕，上下分屏浪费空间。
2. 自动播放一拍一秒，看不清过程，没有实际用途。
3. 画布一次只显示一层，缺少全局目录。希望有一个树状视图展示模块与步骤，点击、高亮与画布同步。

## 结论

### 1. 分屏方向可选，默认左右

- 运行视角下结构图与时序图可左右或上下排列，默认左右，在时序图标题栏一键切换。
- 方向、比例、收起状态都按项目记在本地，不进视图状态与 URL（W-4）。布局树 `PaneLayout` 原本就支持两个方向，只需加一个切换操作。
- 左右排列时收起时序图，它会缩成一条竖栏。

### 2. 取消自动播放

- 回放只由用户驱动：上一步、下一步、拖动进度、指向某一步、选分支。删除播放 / 暂停、速度和时钟同步适配器。
- 视图状态里的 `playing`、`speed` 随之删除。不变式「播放中 ⇒ 无选中」不再需要，焦点规则简化为「跟随 / 钉住」二选一。
- 打开场景时停在开头（第 0 步，尚未开始）。此时面板显示场景概览，按「下一步」走出第一步（R12）。
- 规则变化：
  - R1、R12 改写；V2、V3、V4 去掉与播放有关的部分。
  - F6a 删除。R14 删除，其中「退出场景进浏览器历史」并入 R10。
  - 新增 V7。

### 3. 导航树

- 工作台左侧新增可折叠的导航树，有「模块」「步骤」两个页签（W-7，规则 T1–T8）。
  - **模块树**：系统的完整模块层级。与画布同步展开和高亮当前层次与选中；单击定位、双击下钻。运行视角下标出参与本场景的模块。
  - **步骤树**：回放计划按组合框嵌套的全貌。与时序图、结构图同步高亮当前步骤；单击指向该步，单击分支标题选该分支。
- 树上的操作全部复用已有动作（`revealModule`、`drill`、`seek`、`chooseBranch`），不新增会话规则。原属性面板里的「步骤目录」并入步骤树。
- 按知识划分层次：
  - 「场景的步骤按组合结构怎样嵌套」「哪些模块参与了场景」是关于被描述系统的知识，放模型层场景投影：新增子模块步骤大纲 `outlineScenario`，参与查询新增 `scenarioModules`。
  - 页签、展开状态、导航树宽度只与这块界面有关，留在呈现层组件里，记在本地。

## 实现者提出的细化（来源「议」，待确认）

| 规则 | 细化 | 理由 | 被否决的选项 |
|---|---|---|---|
| R12 | 打开场景停在开头（第 0 步），不是直接停在第一步；在第一步后退、进度拖到 0、单击步骤树的「开头」都回到开头 | 停在开头时面板显示场景概览（说明、触发者、参与模块），舞台上还没有走过的边，第一下「下一步」就是第一条消息，便于从头看起。停在第一步时概览无处可看，第一条消息也不会有「走出来」的过程 | 停在第一步 |
| V7（新增） | 移动播放头（单步、指向某一步、拖动进度）回到跟随 | 原来靠「播放」回到跟随，取消后只剩 Esc。指向某一步本就回到跟随（R13），单步与它同属「看这一步」，应当一致 | 单步不改变钉住（钉住后只能 Esc 解除） |
| N10 | 跳转与定位只在层次改变时进浏览器历史，层次不变时只替换地址 | 在模块树中单击当前层次的模块，本质是选中，不应多出一条历史 | 定位一律进历史 |
| T1 | 进入运行视角时导航树切到步骤页签，退出时切回模块页签 | 进入场景后最常用的是步骤目录；用户仍可手动切换 | 页签不随视角变化 |
| T2 | 模块树的可见性与结构图一致：结构视角下「只看现状」开启时不列目标态模块；运行视角下不受开关影响（L9） | 树里出现画布上找不到的模块，定位后会落空 | 模块树始终列出全部模块 |
| T5 | 运行视角下模块树标出参与模块（帧端点及其祖先，含全部分支）与当前步骤的两端 | 帮助在深层次之间判断「下钻哪里能看到更细的步骤」 | 只标当前步骤的两端 |
| T7 | 步骤树的序号用本层可见消息序号，与时序图、控制条一致；本层不可见的帧不编号并标「本层不可见」 | 序号若与层次无关，会出现「树上第 12 步、控制条第 4 步」的矛盾 | 按帧在计划中的先后编号 |

## 后果

1. ADR-0003 结论 2（四个同步适配器）、结论 4（「播放中 ⇒ 无选中」「只有播放控制能恢复播放」），以及 ADR-0005 中 V3、R14 关于暂停与播放的部分，被本 ADR 修订。
2. 需求、领域模型、架构文档按最终态改写；本项目的架构描述 `model/h5p-arch-desk/` 按代码重新生成，场景「打开场景并回放」去掉时钟驱动的循环。
3. 以后的自由拖拽分屏（§7 后续方向）仍在布局树上扩展；导航树作为左侧固定栏，不进入分屏布局树。
