## 背景

走查续两条：

1. **身份卡滚走**：面板内容一长（如 DeskState 的理解 + 核对 + 相关资料三卡），向下滚动后选中对象是谁、有哪些动作（进入 ⌄、在此设计）全部离开视野，只剩一枚淡色名称胶囊——第十八轮 Y2.4 / Y2.5 为省首屏空间定的「不粘顶 + 胶囊」，实测反而多一步（滚回顶部看动作要单击胶囊）。
2. **图解入口太深**：16 份原理图解补齐后，入口只在相关资料卡（PC-9，条目多于 3 份还缺省收起）与画布节点角标 ▣。选中模块想读原理，要展开卡、找到行、单击——三步。

## 结论

### 1. 身份卡粘顶（V15a、CD-3 改写；CD-4 作废）

身份卡 `position: sticky` 钉在属性列滚动区上沿（`top: 0`），其余卡片从它底下滚过；×（关闭属性栏）随身份卡恒在可视区。名称胶囊（CD-4）与其「单击滚回顶部」机制整体移除——粘顶后身份卡永不滚出，胶囊不可达，留着即死代码。L46 的首屏量法不变：静息态不滚动，粘顶与否不影响理解卡底边的位置。

### 2. 名称行的「图解 ›」（CD-3 扩展）

有图解的模块（EX-1），身份卡名称后附「图解 ›」小链接：单击在资料区以预览标签打开该图解（WS-5）；依据过期时提示进悬停（EX-7，不在标题行占位）。三步变一步，且选中即可见——图解是模块的一项信息（ADR-0055），入口与 ID、类别徽标同级是它的正确位置。

### 3. 选中即自动打开（WS-8 的例外）

结构 / 交互视角下，选中变为另一个带图解的模块时，DeskState 自动把该图解以预览标签打开——负责人原话「有原理图解的模块选中后自动显示附加栏并展示原理图解」。边界：

- **已在资料区开着（含固定）不再动**：不降级固定为预览、不重复激活。
- **运行视角不自动**：资料区在运行视角归时序图（WS-8 原规则）；标题行的「图解 ›」仍可手动打开。
- **草图编辑不自动**：编辑态画布是草图，面板换成草图面板。
- **从图解 iframe 点链接来的选中豁免**（EX-3 口径不变）：正在读父图解时点模块链接是「跳转到那个模块」，资料区跟着跳会打断阅读；选中带 `source: 'explainer'` 标记，自动打开跳过。

## 否决的方案

| 方案 | 为什么不 |
|---|---|
| 保留胶囊、不粘顶 | 胶囊只回答「这是谁」，不回答「有什么动作」；回顶部仍要多一次单击 |
| 只做名称行按钮、不自动打开 | 「选中即想读原理」是主路径，三步里省掉的两步正是按钮已经省掉的——自动打开把它变成零步；预览语义保证不累积、被下一份替换（WS-5） |
| 自动打开也固定标签 | 固定标签会在资料区越积越多，违背预览「轻」的语义；想固定有双击 |
| 运行视角也自动 | 运行视角的资料区主语是时序图，图解挤进去会顶掉回放参照；手动入口保留 |

## 后果

- 组件：`Panel.vue`（sticky、移除 mini 机制）、`ModulePanel.vue`（名称行 titlerow + 图解 ›）、`DeskView.vue`（× 注释）、`useDeskState.ts`（WS-8 例外 watcher、`select`/`revealModule` 的来源标记）、`ExplainerDoc.vue`（iframe 选中带来源）。

- 文档：02 的 V15a / CD-3 / CD-4 / WS-8 / L46、01 §6.43 第 3 条、自描述 `present.panel` 与 `runtime.canvas` 的 principle 按代码改写。

## 待裁（「议」规则）

- WS-8 例外的口径（结构 / 交互视角、选中「变为另一个」才触发、豁免来源清单）。
- 名称行「图解 ›」是否也标依据过期（现为悬停提示）。
- URL 直达（`?sel=` 指向带图解模块）同样自动打开——现为是，若嫌首访打扰可收紧为仅交互选中。
