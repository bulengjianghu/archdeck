# ADR-0023：第三轮——草图作为意图载体、人确认层、第三类事实；推进策略

- 状态：已采纳（实施中）
- 日期：2026-10-22
- 决策人：项目负责人（产品定位评审后的裁决与方向，2026-10-22）
- 关联：修订 [ADR-0002](./0002-design-versions.md)（设计 = 草图 + 轮次）、[ADR-0019](./0019-human-owned-writes.md)（人拥有文件新增草图与确认记录）、[ADR-0020](./0020-local-workbench.md)（定位不变，补推进策略）；需求组 SK、RV、HS 与 D 组新增条目（01）；规则 X、Z、J、S15–S18、B6（02）；原则上溯：[ADR-0028](./0028-positioning-and-principles.md)（产品定位与原则）

## 背景

对产品定位、功能与界面做了一次完整评审，围绕一个问题：架构师在 AI 时代能否靠本工具掌握项目、从架构视角持续演进，并避免 AI 写代码太快导致的失控与架构师的认知卸载。结论：「看见」「对照」已能支撑；「守住」只在工具内闭环；对认知卸载缺少机制——当前版本整份由 AI 重新生成，架构师从未逐模块签字，AI 改掉他看过的内容时无人告知；架构师的意图（层与第二级模块、层规则）也放在 AI 可整份重写的文件里。

## 负责人裁决

### 推进策略（长期有效）

- 迭代以架构台自身为目标：发现的问题尽快形成优化项执行，形成闭环飞轮。
- h5player 只做两件事：持续生成描述；作为成熟的老项目验证效果，避免视角只停留在架构良好的新项目上。不在 h5player 上做治理或修复。

### 方向

架构师只做核心、骨架的设计与原则约束，覆盖到什么层次、哪些模块由架构师自选；大部分设计工作由 AI 完成。四件事各一个载体：

| 事 | 载体 |
|---|---|
| 意图：哪里必须按架构师的意思来 | 草图（任意范围与深度的人拥有局部描述；骨架是持久草图） |
| 自由：哪里让 AI 发挥 | 草图没画的地方 |
| 理解：架构师看过并认可了什么 | 确认层（`reviewed.yaml`） |
| 证据：代码实际上是什么样 | 代码事实（已有）、git 历史（热点与时间耦合）、步骤的候选调用点 |

### 裁决表

| 事项 | 裁决 |
|---|---|
| 草图：范围（出现的实体，子树可封闭）、生命周期（持久 / 实现一致后归档）、结局（归档并转为确认记录 / 晋升替换持久草图）、核验（对设计各轮与当前版本）、指纹门禁、ID 纪律；二期画布编辑 | 做 |
| 人确认层：确认记录、指纹覆盖职责 / 接口 / 直接子模块、需复核进返工清单、草图归档批量写入 | 做 |
| git 历史的第三类事实：修改热度、缺陷热度、跨模块时间耦合，画布叠加缺省关闭 | 做 |
| 场景证据：场景声明测试文件；步骤从代码事实匹配候选调用点，四档等级 | 做 |
| 首页违规显示「±N · 存量 M」；问题页签按类别筛选 | 做 |
| 门禁接进 h5player 仓库 | 不做（推进策略） |
| 描述漂移提示、描述迁回 h5player 仓库 | 不做 |
| 规则扩展到外部包 | 不做 |
| 单独的「设计落地核验」 | 并入草图核验 |

### 被否决的选项

- 骨架专用的意图文件（只约束层与第二级）：被「草图是统一概念」取代，因为局部设计同样需要有约束力的意图，且骨架只是生命周期不同。
- 只存确认的内容指纹、不存摘要：需复核时只能说「变了」，架构师仍要读全文；采纳存摘要以显示差异。
- 3D 城市图呈现热点：另做一套视图与交互而信息不增；采纳画布叠加 + 树排序。

## 结论

1. 新增人拥有文件：`intent/*.yaml`（持久草图，含骨架）、`designs/<设计>/sketch.yaml`、`reviewed.yaml`；指纹记在 `governance/owned.json`，`lint:model` 校验。
2. 设计 = 草图 + 轮次：草图是尺子，轮次是被量的东西；核验结果进返工清单「草图偏差」。
3. 确认记录来源两种：人在面板确认；草图归档批量写入。
4. 画布新增「演化」叠加组与「步骤证据」等级标记，缺省关闭 / 只标异常，遵守 ADR-0018 的通道原则。
5. 实施顺序：小改动批先行；草图一期、确认层、热点并行；候选调用点在场景证据字段之后；草图画布编辑最后；完成后重新生成本项目描述。每个大任务先更新 01–04 再实现，完成后补核心路径 E2E。
6. 新增规则先标「议」，实施结束后一次列给负责人裁决。

## 后果

1. 04 §1 的拥有者表与 §5 设计版本流程重写；ADR-0002 结论「设计版本由 AI 起草」修订为「架构师画草图、AI 展开」。
2. `modules/layers.yaml` 不再定义层与第二级模块，由 `intent/skeleton.yaml` 承担；AI 生成只能在骨架之下挂子模块。
3. 架构台自身成为第一个样本：本项目的骨架、phase2-dynamic 的回溯草图、核心模块的确认记录、热点与调用点都先在本项目上验证，再观察 h5player。
