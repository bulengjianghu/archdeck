# ADR-0043：一个词叫「层」、状态记号区分来源；节点注记的位置表

- 状态：已采纳，已实现（第十四轮波 0：F4、F16）
- 日期：2026-10-28
- 决策人：项目负责人（2026-10-28「按推荐定稿」：F4 用户可见统一叫「层」、状态记号区分来源；F16 静息态上限 3、位置表出图后复核）；起草：第十四轮主线会话
- 关联：[ADR-0038](./0038-tiers-by-dependency.md)（算出的层 L28、L29）、[ADR-0027](./0027-module-roles.md)（共用 ×N、折叠计数）、[ADR-0031](./0031-three-views-and-structure-view.md)（结构视角角标）、[seeing.md](../system/seeing.md) §2.3、§3、§7

## 背景

1. 「层」一词双载：描述里 `kind: layer` 的声明层与 L28 按值依赖算出的层带（tier）同名，F8 要两者同一画法、F2 要把算出的层提炼成声明的层，读者需要分得清哪个是原则、哪个是证据。
2. 节点上已有十几类注记（稳定度色条、入 · 出 · 表面、界外、影响面、变更、端口、表面点阵、边界角色、下钻、共用 ×N、热度、环编号），各自落位：环编号与「共用 ×N」在顶边有端口时挪到底边，热度在角标下移时让到左边——同一种注记位置不固定；第十四轮还要加「另直连 N」（F9）、环内计数（F10）、组织信号（F5）。

## 裁决

1. **F4 一个词**（定）：用户看到的一律叫「层」；来源与状态交给状态记号——算出 / 待确认 / 已确认（L36）：声明的层写在带标题旁；算出的层整组同一状态，写在画布角一次（议：层带文字区是走线障碍，层带上加记号会改走线：每条带都写 h5player 交互视角压节点 2 → 10、只写最上一条 2 → 11、不让走线避开 2 → 3，都违反 L30 只降不升）。规则与代码保留 tier（算出的层）与 layer（声明的层）的区分。备选「行 / 深度 / 档」未采纳：多一个概念，且 F2 提炼后同一组节点要换名字。
2. **F16 位置表**（上限 3：定；位置与优先级：议，出图复核）：九个槽，每槽一个维度（L37）。要点：
   - 环编号从上边框挪进名称行（身份），不再与端口记号争顶边——顶边右半永远是端口（线的落点）。
   - 「共用 ×N」从上边右挪到下边右，与将来的「另直连 N」同槽：两者都是「没画出来的线」的计数。
   - 热度色块固定在右下角内，不再随角标让位。
   - 写字的注记（状态、环、量、没画出来的线、界外）静息态每节点最多 3 个，超出的按「状态 ＞ 环 ＞ 量 ＞ 没画出来的线 ＞ 界外」收起，悬停或选中该节点时全部出现。

## 后果

- 后续各项的节点注记都有固定的槽，不再各自加角标；E2E 中对环编号、共用角标位置的断言随之更新。
- 结构视角的大层次里，「界外」与「共用 ×N」在静息态常被收起（量与环优先）；需要时悬停节点即可看到。
