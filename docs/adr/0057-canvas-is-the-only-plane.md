# ADR-0057：画布是唯一的平面——工具栏治理、卡片与回放胶囊

- 状态：已采纳（负责人 2026-10-31 同意第十八轮开工，D1–D7 按推荐）；Y1 已实现（第十八轮 X1），Y2、Y3 见下文对应两节；标「议」的细则待裁（见末节）
- 日期：2026-10-31
- 决策人：项目负责人
- 部分修订：[ADR-0054](./0054-workspace-props-and-dock.md) 结论 1（工具栏的元素）、结论 2（「并排 / 悬浮」字样）；[ADR-0056](./0056-interactive-legend.md) 中「显示 ▾」旁的摘要
- 关联：需求 W-1、W-2、W-3、H-3、C-11；规则 WS-1、WS-3、L49、G22（修订）、TB-1–TB-11（新增）；原则 C6（CLAUDE.md §2 第 11 条）、C5

## 背景

第十七轮落地后，负责人认为顶部工具栏太杂乱、属性栏面板感太硬：工具栏挤着 15 个元素（导航开关、版本下拉、编辑骨架、新建设计、视角、「显示 ▾」和它的摘要、面包屑、220px 搜索框、?、专注、「并排 / 悬浮」、▤ 属性、▣ 资料），下面还有一整行黄色的源码提示条。运行视角加资料区时工作列变窄，视角段和面包屑被挤压。

按「它回答什么问题」盘点（候选文档 `00-toolbar-replay-cards.md` §1.1），这些元素混了四类东西：看什么、怎么摆、我在哪、对项目做什么。只有前两类改变工作区的显示，属于工具栏。原型 v4.3（`proto-dock-v4.html`）经四轮修订定稿。

## 结论

### 0. 原则 C6

**画布是唯一的平面，其余都是浮在上面的卡片；工具栏只放「改变工作区显示什么」的控件。**

- 「我在哪」（层次、问题数、源码与版本状态）贴着画布放，在画布左上角——位置信息贴着它描述的那张图（C2）。
- 「对项目做什么」（切换版本、编辑骨架、新建设计、换项目）放在导航栏顶部的项目菜单里，即工作区切换器（Slack、Notion、Linear、Figma 的侧栏顶部）。
- 状态用胶囊，不用整行的横条。

### 1. Y1 工具栏与项目标题（TB-1–TB-11）

```text
┌ 项目名 ▾ ───┐┌ ☰ [结构|交互|运行 · 场景 ▾ ×]          显示 ▾• │ ⌕ ⤢ ▤ ▣ ⋯ ┐┌ [时序图 ×] [源代码 ×]   ⊟ × ┐
├─────────────┤├──────────────────────────────────────────────────────────────┤├──────────────────────────────┤  ← 一条横线（TB-11）
│ 模块 文件 问题││ 根层 / 播放器 Kit   ⚠ 1   描述落后 150 个提交   [✎ 草图 ×]    ││                              │
│             ││ 画布                                          属性卡片        ││  资料                        │
└─────────────┘└──────────────────────────────────────────────────────────────┘└──────────────────────────────┘
```

1. **工具栏只留 8 组**（TB-1）：左侧「看什么」（☰、视角段），右侧「怎么摆」（显示 ▾、⌕、⤢、▤、▣、⋯），中间留空。只有视角段与「显示 ▾」带文字；视角是主控件，「显示」没有通用图标。运行段的场景名最多 12 字。
2. **图标统一**（TB-2）：16px 线框 SVG，开着的浅色底，悬停给文字与快捷键（Claude Code 顶栏右侧的做法）。「并排 / 悬浮」字样删去，写进 ▤ 的悬停提示（WS-3 修订）。
3. **「显示 ▾」去摘要**（TB-3，L49 修订）：有非默认设置时按钮上一个点；隐藏了什么由画布角的留痕说明（L45），摘要与留痕重复（C1）。
4. **搜索走 ⌘K**（TB-4）：⌕ 或 ⌘K 在工具栏中央下拉出搜索面板，结果与键盘沿用原搜索。
5. **帮助收进「⋯」**（TB-5），菜单里另有「快捷键」；图例里的「?」照旧。
6. **项目标题区**（TB-6）：导航顶部 44px，项目名 ▾，菜单里是版本、编辑骨架、新建设计、所有项目。
7. **画布标题行**（TB-7–TB-9）：面包屑移到画布左上角，以「根层」开头（项目名只在左上角出现一次）；同一排是 ⚠ 问题、源码胶囊、非当前版本时的版本胶囊（× 回当前版本）。
8. **源码提示条降级为胶囊**（TB-8，G22 修订）：「描述落后 N 个提交」，单击展开原文；落后超过阈值或源码不可用时着警示色。
9. **资料区通顶**（WS-1 修订、TB-10、TB-11）：资料区从窗口顶到底，标签栏在最顶上，工具栏止于资料区左侧，两者之间一条通高的分割线；标签栏右端是 ⊟ 分屏与 × 全部关闭。项目标题区、工具栏、资料区标签栏的底线成一条横线。

### 2. Y2 卡片（CD-1–CD-6）

#### 背景

第十七轮的属性栏仍然是一块「面板」（第十八轮计划 `00-toolbar-replay-cards.md` §3.1）：左侧一条贯穿全高的竖边框；头部粘顶、白底加分隔线，是一条固定标题栏；卡片装在灰底的面板里，面板套卡片两层框。悬浮时整列是一块大浮板。负责人看完认为「面板感太硬」，要求参照 Claude Code 右侧「环境 / 上下文 / 输出内容」那样一块一块的卡片。

中间试过「背景加浮块」（v4.1：并排时属性列有自己的浅灰底，悬浮时整列是浅灰浮板、白卡装在里面），理由是卡片之间露出画布的线条会乱。负责人第三轮意见（v4.2，§6.4）否决了容器：**卡片直接立在画布上，不装进容器**。

#### 结论

1. **一组卡片设计变量**（CD-1）：白底、1px 浅边框、圆角 12、轻投影、卡间距 12，放在共用样式 `src/styles.css`（`--card-bg`、`--card-border`、`--card-radius`、`--pill-radius`、`--card-shadow`、`--card-gap`，类名 `.desk-card`、`.desk-pill`）。属性卡片、图例、缩放胶囊、回放胶囊、画布左上角的问题 / 源码 / 版本胶囊都用它——工作区里除了画布，只有这一种东西。
2. **属性列不是面板**（CD-2）：并排时底色就是画布的底色，没有竖分隔线、没有底板；悬浮时也没有整列的浮板，卡片之间的空隙透到画布，空隙处的点击、拖动、滚轮落到画布上（`pointer-events`）。
3. **头部变成第一张「身份卡」**（CD-3，修订 V15a）：名称 16px 半粗；ID 等宽灰字加类别胶囊；「进入 ⌄」「在此设计」改为小号描边按钮另起一行；× 悬停时才显出。身份卡**不粘顶**，随内容滚走——滚走后属性列顶部出现一枚淡色的名称胶囊（CD-4，D7），回来即消失。
4. **卡头统一**（CD-5）：「小号粗标题 ▾」，▾ 跟在标题后，结论靠右；去掉卡头的底色与分隔线。
5. **不变的**：卡片的内容与顺序（ADR-0053）、330px 宽度、并排与悬浮的判定（WS-3）、属性跟随选中与 ▤ 的开关逻辑（WS-2）。首屏守 L46 按新的版式量，kit、kit.kernel 仍须一屏读完。

#### 理由

- **C6**：一个平面加一种卡片，读者只需分辨「图」和「关于图的卡片」两种东西；面板、浮板、标题栏都是多出来的第三种。
- **C5（参照 Claude Code）**：Claude Code 右侧的卡片直接立在背景上，卡头是「标题 ▾」，身份信息本身也是一张卡。
- **空隙透到画布**：卡片之间露出画布是负责人的选择（§6.4 否决了 v4.1 的底板）。既然看得见画布，就应当点得到画布，否则空隙是一块看得见、点不着的死区。

#### 后果

- 悬浮时卡片之间露出画布的线条；卡片的投影把卡与画布分开，读起来仍是一块一块。
- 身份卡滚走后，「这是谁」靠画布上的选中高亮与名称胶囊提示；× 随身份卡滚走，关闭属性栏另有工具栏的 ▤。
- 首屏可用高度少了粘顶头部的那一截之外的变化：身份卡多了一行动作、卡间距从 6 变 12，理解卡的上沿下移，实测见第十八轮 X2 报告。

### 3. Y3 回放胶囊（CD-7–CD-10）

#### 背景

回放控制条（PlayerBar）是工作列底部贯穿整行的一条：上一步 / 下一步、进度条、「第 n / N 步」、路线总览、停在分支点时的分支选择。负责人问能否放进右侧时序图（D5）。分析见计划 §2.1：回放进度是**场景的状态**，画布、时序图、步骤树是它的三个投影（ADR-0031）；控件放进时序图，就随时序图的关闭、资料区的隐藏而消失，只好在画布上再放一份，于是有了两个家（违反 C1）。

#### 结论

1. **回放控制不进时序图**（D5，CD-10）：时序图里单击某一步即跳到那一步（已有），键盘 ← → 单步，两条写进帮助。
2. **改为工作列底部居中的浮动胶囊**（CD-7）：`◀ 第 n / ≥N 步 ▶ ━●━ 路线 ▾`，宽度随内容，与左下角的缩放胶囊同一行、同一卡片样式。
3. **避让悬浮卡片**（CD-8）：属性卡悬浮时，胶囊居中于剩余画布（复用 `--canvas-inset`）；剩余宽度放不下时居中于整个画布，悬浮的卡片列底部让出胶囊的高度。
4. **路线平时只显示编号**（CD-9，修订 F6f）：走到 alt 未选的分支时变成警示色的「选路线 ▾」；单击展开胶囊上方的浮层，里面是路线总览与分支选择（BranchChooser 行为不变），停在分支点时浮层自动展开。

#### 理由

- 胶囊不随资料区、时序图、专注模式消失，读画布时就在眼下（计划 §2.1 方案 A）。
- 不再占一整行，画布多出一行高度。
- 路线总览常驻展开会把胶囊撑成一整行；平时只要「走的是哪条路」，编号就够，要改选时再展开。

#### 后果

- 读时序图时控制在左边，靠单击时序图消息跳步与 ← → 弥补。
- 胶囊浮在画布底部，可能盖住画布最底下的一点内容；适应时的 8% 边距（约 60px）大于胶囊所占的 52px，所以适应后的图不被盖住（CD-8，适应不另留边）。

## 理由

- **按频率与问题分家**：高频控件可见，低频的收进菜单；读的信息贴着它描述的对象放（C1、C2）。元素从 15 个降到 8 个后，工作列再窄也不会挤压视角段（W2、W4 报告里运行视角被压窄、面包屑被压没的问题随之消失）。
- **参照 Claude Code（C5）**：顶栏右侧是一排同尺寸的线框图标、只有一处带文字；搜索走 ⌘K；项目与环境在侧栏顶部或卡片里，不在顶栏。
- **项目菜单是工作区切换器**：架构台的项目菜单还管版本与设计，属于「切换和对整个空间的操作」，Figma 的文件菜单里同样有版本历史。

## 后果

1. 工具栏不再有版本下拉、编辑骨架、新建设计、面包屑、搜索框、帮助按钮、「并排 / 悬浮」字样；E2E 的选择器按新位置迁移（项目菜单、画布标题行、⌘K、⋯ 菜单）。
2. 导航树收起时，版本切换要先展开导航（运行视角缺省收起导航，W-1）。版本胶囊的 × 仍可直接回到当前版本。
3. 源码提示不再占一整行，画布多出约 26px 高度；源码读取失败第一次在界面上可见（「源码不可用」胶囊）。
