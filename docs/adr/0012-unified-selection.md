# ADR-0012：统一选中，去掉焦点概念

- 状态：已采纳（已实现）
- 日期：2026-10-21
- 决策人：项目负责人（方向与「结论」各条，2026-10-21 确认）；实现者提出的细化规则（来源「议」）列在下文，待负责人确认
- 关联：需求 D-7、D-10–D-12、D-17、D-18、SR-7，验收标准 §6.8；领域模型 §1.3、§1.4、§2（V2–V4、V7、V9、N2、N8、N9、N13、R12、R13、R15、R16、T4、T7、G16）；ADR-0003、ADR-0006、ADR-0008、ADR-0011

## 背景

1. **下钻 / 返回上级后「选中了很多步骤」**。下钻会钉住被下钻的模块（V3），返回上级会选中退出来的模块（N8），而钉住时突出该对象参与的全部消息（R15）。ADR-0011 只修补了「钉住当前层次或其祖先」一种情况，返回上级后钉住的子模块仍会让大片消息同时突出。
2. **「焦点」已没有存在的理由**。它源自二期的自动播放（ADR-0003）：播放中面板要跟着当前步骤走，用户指向对象时要「钉住」，于是在选中之外多了一个主语。ADR-0006 取消自动播放后，播放头只由用户移动，「跟随 / 钉住」只剩一个作用——决定面板显示什么，但它让用户同时面对「选中」「焦点」「当前步骤」三个指针。

## 结论

### 1. 选中是唯一且排他的主语

- 模块、关系、视图边、参与者、文件、**步骤**、**场景**都是可选中的对象，只能单选；选中新的即取消旧的（V2）。
- 删除「焦点」「跟随 / 钉住」概念、`focusOf` 与面板的「已钉住」提示条。

### 2. 播放头退为内部的「进度」

- 进度是场景走到哪一步（帧 ID），用于「下一步」、走过的边、进度条；不是用户直接操作的概念。
- **不变式**：选中的是步骤时，它就是进度所在的那一步（V7）。
  - 单步、指向某一步（单击消息、步骤树、结构图步骤序号、运行信息中的步骤）、拖动进度 = 选中那一步并移动进度。
  - 选中其他对象时进度不动；「下一步」从进度处继续，并选中下一步。
- **视图状态不加字段**：运行视角下 `selection` 为空即表示「选中进度所在的步骤」，进度在开头时即「选中场景」。不变式因此由表示本身保证，不需要同步两个指针。

### 3. 进入场景、Esc、层次切换

| 操作 | 结果 | 规则 |
|---|---|---|
| 进入场景 | 选中场景本身（相当于第 0 步，面板显示场景概览）；按「下一步」选中第 1 步；从带 `step` 的链接进入则选中该步 | R12 |
| 回到开头 | 选中场景 | R12 |
| Esc / 单击空白（运行视角） | 回到选中进度所在的步骤；进度在开头时选中场景 | V4 |
| Esc / 单击空白（结构视角） | 维持 N9、N13 | N9、N13 |
| 退出（返回上级） | 在父层选中退出来的模块；运行视角同样生效，之前选中的步骤或文件被取消 | N8 |
| 进入（下钻） | 运行视角选中被下钻的模块；结构视角清空选中 | V3、N2 |

### 4. 显示原则：只有被选中的那一个对象用选中样式（R15）

| 选中 | 时序图 | 结构图 |
|---|---|---|
| 步骤 | 只有该消息用选中样式；配对的调用 / 返回（F7）只加浅色「配对」标记 | 其余走过的边与步骤序号变灰 |
| 模块 | 突出它所在的泳道（泳道头与生命线），不突出消息；模块在本层不是独立泳道时突出包含它的泳道；是当前层次本身或其祖先时不突出 | 不灰化 |
| 文件 | 突出其归属模块所在泳道（规则同模块） | 不灰化 |
| 关系 / 视图边 | 突出两端泳道 | 不灰化 |
| 参与者 | 突出其泳道 | 不灰化 |
| 场景 | 不突出 | 不灰化 |

- 选中的不是步骤时，进度位置在时序图上只用步骤序号旁的小标记表示，不用选中样式。
- 结构图的舞台显示（走过的边、当前消息流动）仍按进度，不随选中变化。
- 原 R15「钉住时突出参与的全部消息」与 ADR-0011 的「钉住当前层次或其祖先时按跟随」由此取代：任何时刻都不会出现多条消息同时被选中的观感。
- 「某个模块在本层是哪条泳道」是关于被描述系统的知识，由模型层时序模型提供查询 `lanesOf`；「选中什么就突出什么」是会话规则，留在视图状态层的 `emphasisOf`。

### 5. 面板与 URL

- **面板按选中分派**（V2）：步骤 → 步骤面板；场景 → 场景面板；其他对象在运行视角下仍是「运行信息在上、结构信息折叠在下」（V6）。
- **URL**：选中步骤时不写 `sel`，`step` 即表示选中该步；选中场景时既无 `sel` 也无 `step`；选中其他对象时写 `sel`，并保留 `step` 表示进度。编码与原来一致，旧链接（`sel` + `step`）按新语义解析即可。

### 6. 步骤树（T7）

- 选中的帧用选中样式；本层合并为同一条可见消息的其他帧用浅一级的「同一步」样式，并注明「本层合并为 1 步」。

## 实现者提出的细化（来源「议」，待负责人确认）

| 规则 | 细化 | 理由 | 被否决的选项 |
|---|---|---|---|
| V4 | 运行视角下选中的已是进度所在的步骤（或场景）时，Esc 按 N9 返回上级 | 保留「Esc 逐级退出」的习惯，与结构视角一致；否则运行视角下 Esc 在多数时候无事可做 | Esc 无效果；Esc 退出场景（退出场景有显式入口，误触代价大） |
| R16 | 选中的模块在本层包含多条泳道（如边界一侧的父模块、分层总览中含核心模块的层）时，突出它包含的全部泳道；选中文件归属多个模块（G6）时取并集 | 「所在泳道」的自然推广：这些泳道都属于它 | 不突出（选中了却在时序图上找不到） |
| R16 | 选中步骤时，配对消息所在的边也不变灰 | 调用与返回在结构图上通常是同一条边，只保留选中消息的边会把同一条边灰掉，自相矛盾 | 只保留选中消息所在的边 |
| R16 | 选中的步骤在本层不可见（R11）时不突出、不灰化 | 本层没有可用选中样式的消息，全部灰化会误导 | 按选中步骤灰化其余全部 |
| R13 | 指向合并消息中的后一帧时仍选中这条可见消息的第一帧（落点不变）；被单击的帧在步骤树中显示为「同一步」 | 与单击时序图消息的落点一致；进度若停在后一帧，下钻后会落在另一条更细的消息上 | 进度停在被单击的帧 |
| T7 | 选中的不是步骤时，步骤树中进度所在的帧只加小标记，不用选中样式 | 与时序图一致：任何时刻只有一个对象用选中样式 | 仍按「当前」高亮 |

## 后果

1. ADR-0003 结论 4、ADR-0006 结论 2 中的「跟随 / 钉住」与细化 V7、ADR-0008 结论 2 的「焦点突出」、ADR-0011 结论 1 被本 ADR 修订或取代。
2. 需求、领域模型、视图状态与工作台专题按最终态改写：概念「焦点」删除，§1.4 改为「视角与选中」，「播放头」改称「进度」。
3. 代码：视图状态转移的子模块「视角与焦点」改为「视角与选中」（`selectedOf` 取代 `focusOf`，`emphasisOf` 改为返回选中消息、配对消息与突出的泳道）；模型层时序模型新增 `lanesOf`；时序图、结构图、步骤树、属性面板按新的显示原则调整。视图状态与 URL 编码不变。
4. 本项目的架构描述 `model/h5p-arch-desk/` 随代码更新。
