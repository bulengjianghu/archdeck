## 背景

理解卡搬去辅助栏理解页（事实卡 + 故事）后，「画布即平面」的沉浸式版式成为主路径的障碍：资料区自动打开挤压画布引发几何漂移，悬浮卡片的指针劫持与单击拦截造成一类不稳定（走查与 E2E 反复踩中）。

## 结论

1. **顶栏拉通**：项目菜单住栏首，工具栏横跨全窗；TB-1 的「工具栏量宽、资料区让位」机制删除。
2. **双栏主形态**：画布（≥640）+ 辅助栏（WS-4 标签组）。选中面板 = **实底抽屉**：宽度够时挤压画布，不够时浮在画布右侧、不透传点击；缺省收起、开关与宽度记本地；运行视角自动收起（步骤 / 场景面板与运行信息都在辅助栏步骤节）。
3. **导航树 = 画布左缘浮层抽屉**：不挤压画布，两视角缺省收起、按视角记本地；草图编辑自动收起。
4. **理解页（facts 资料类型）**：辅助栏一页 = 事实卡（架构台从描述渲染）+ 故事（有图解时）；选中任何模块自动打开（WS-8 例外扩展：URL / 状态同步立即开，用户点选走 250ms 稳定窗，运行视角 / 草图编辑 / 图解 iframe 来源豁免）。
5. **运行视角右栏**：时序图 + 步骤节常驻——选中步骤 → 步骤详情（作用、输入输出、代码证据）、场景 → 概览、其他对象 → 运行信息（RunSection）；抽屉在运行视角不渲染步骤 / 场景面板（一个主语）。

## 后果

- CD-2 的 pointer-events 透传、悬浮避让（CD-8 部分）、TB-1 让位机制删除；卡片设计变量（CD-1）保留为抽屉 / 卡片样式。
- PC-9 相关资料卡退役（Actor 面板保留）；「图解 ›」名称行按钮随理解卡搬家删除（入口 = 选中自动打开 + 画布 ▣）。
- E2E：14 个 spec 按新版式重写；已知负载敏感：并发 workers=4 下部分用例偶发超时（顺序执行稳定通过），机器负载相关。
