- 决策人：项目负责人
- 部分取代：[ADR-0017](./0017-display-panel.md)（「显示」面板的位置与合一、第二轮「先设置后图例」）；第十五轮 G13 的「图例行只读、一行不兼两职」（02 的 L45 旧文）
- 关联：需求 W-2、W-10、R4（第十七轮）；规则 L45（改写）、L47（修订）、L48–L51（新增）、L8、L9、L19、V8、K9、O12、J5；原则 C1、C3、C4、C5

## 背景

第十五轮把画布的显示控件收进右下角的「显示」面板，分上「设置」下「图例」两块，图例行只读。实测有三个问题（分析见第十七轮计划 `00-look-panels.md` §1）：

1. **重复**：四类关系各有一行定义文字，「设置 · 关系筛选」一次（带勾选框），「图例 · 关系」原文又一次（带示意线）。代码事实、组装、演化同样各占两处。违反 C1。
2. **遮挡**：面板浮在画布右下，展开后盖住画布右侧约三分之一。
3. **教学内容混进图例**：「三问」判定树、「四修饰 · 读完类型再读」是第一次读图时要学的，学会之后每次打开都是噪声。

设置是**写**（决定画什么，低频、有状态），图例是**读**（解码画了什么）。两者的交集——既有开关又有记号的项——在成熟产品里是同一行：ECharts、Plotly、Grafana 点图例项显示或隐藏系列；QGIS 图层行是勾选框 + 符号 + 名称；Google Maps 把不常用的图层开关收进角落的菜单。

## 结论

### 1. 按「有没有画布记号」分两处，一个开关只出现在一处（L45、L49）

| 类 | 去处 | 项 |
|---|---|---|
| (a) 有开关也有记号 | **图例行即开关**：示意 + 名称 + 勾选态，单击整行切换，关着的行淡色常列 | 交互视角：关系五类（四类 + 迁移期未分类）、代码事实、组装、演化热度、时间耦合；结构视角：只引类型（依赖的档里那一行） |
| (b) 只有开关 | 工具栏 **「显示 ▾」** 下拉菜单，按视角给项 | 边界节点、只看现状、热度口径（修改 / 缺陷）；结构视角：只看交互使用、只看未解释、总是展开表面；运行视角：交互关系的显示方式（隐藏 / 淡显 / 全显） |
| (c) 只有记号或教学 | 记号留在图例只解码（L47 照旧）；教学内容进帮助（L51） | 修饰各行、标签词、节点、回放、结构视角的形态 / 醒目度 / 收起 / 表面 / 规则 / 指标、共享通道；「三问」「四修饰」讲解 |

运行视角的关系类型行只读（回放不受筛选影响，L9）。隐藏画布内容的开关照旧在画布角留痕计数、单击撤销（L45 后半不变）。

### 2. 图例在画布右上角，默认收成「图例 ▾」（L48）

第一次进入某个项目时展开，之后按本机记住（按项目，不分视角）。画布角的留痕与提示排在图例之下、同一列，图例卡高度上限为画布高度的一半、超出在卡内滚动，所以图例再长也不盖住它们；属性栏悬浮时整列让出卡片宽度（WS-3 的 `--canvas-inset`）。各组可折叠、按视角记。

### 3. 只列当前画面出现的记号；关着的开关行例外（L47）

出现集合照旧在状态层一处派生。新增一条：开关行关着时**常列、淡色**——关掉的类画面上不出现，但行要留着才能再打开。

### 4. 教学内容只在帮助（L51）

「三问」「四修饰」的讲解只在「帮助 · 怎么读这张图」的「读一条线」一节；图例关系组标题旁一个「?」打开帮助并定位到这一节。图例里修饰的各行是画布记号，留下只解码。

### 5. 在用到的地方解释（L50）

悬停一条线或线上的标签时，提示末尾另起一段「图例 · …」附上这个记号在图例里的那一句话。文字与图例行取自同一份词表（`display/labels.ts`），不另写（C1）。

### 6. 不动的

时序图的箭头约定仍在时序图标签内容区顶部的「图例」（WS-10）。「显示 ▾」旁的摘要沿用第十五轮折叠摘要的口径（L49）。

## 与原型的偏离

| 原型（proto-dock-v3） | 实现 | 理由 |
|---|---|---|
| 图例行只有淡色表示关着 | 行首加勾选态（✓ / 空框）再加淡色 | QGIS 图层行的做法；只靠透明度时，关着的行与「本层没有」的行难分，色弱读者也难辨 |
| 「图例 ▸ / ▾」文字标题 | 胶囊按钮「图例 ▾」，展开时与卡片接成一体 | 与画布角的留痕胶囊同一视觉语言，收起时只占一枚按钮 |
| 原型没有画布角留痕 | 留痕排在图例下方同一列 | R4.6；同一列避免两块浮层抢右上角 |
| 原型的热度没有口径 | 热度开关在图例、口径在「显示 ▾」 | 口径（修改 / 缺陷）没有自己的记号，属于 (b)；开关有三档角标，属于 (a) |

## 否决的方案

| 方案 | 否决理由 |
|---|---|
| 只把「显示」面板拆成两个浮动面板 | 画布上多一块遮挡物，治标不治本（C4） |
| 图例行只读、开关全进「显示 ▾」 | 设置与图例之间仍有一一对应的重复行（C1）；读图时想关一类线还要去另一处找 |
| 关着的类从图例消失（严格按 L47 出现集合） | 关掉之后就找不回来，只能靠画布角留痕；R4.3 要求淡色 |
| 释义在组件里各写一份 | 与图例行文字会漂移（C1） |

## 待裁（「议」规则）

| 编号 | 事项 | 推荐与理由 |
|---|---|---|
| L45 | 结构视角的「只引类型」归图例行（不进「显示 ▾」） | 是：它有自己的记号（点线那一档），按 (a) 归类才不会在图例与菜单各出现一次；需求 R4.1 的列举里没有它 |
| L45 / L49 | 热度的开关在图例、口径在「显示 ▾」；热度关着时选口径只记下、不打开 | 是：开关对应三档角标（有记号），口径没有记号；选口径就打开会让「显示 ▾」里也有了一个开关 |
| L48 | 收放按项目记、不分视角；卡高上限为画布的一半；各组折叠沿用按视角记 | 是：R4.3 说「第一次进入项目时展开」，按项目记最直接；半高保证下面的留痕总看得见 |
| L49 | 摘要沿用第十五轮口径，包括来自图例开关的「隐藏 N 类关系」「代码事实已关」 | 是：摘要是状态汇总，不是开关行，不算重复；图例收起时它是唯一能看到非默认设置的地方 |
| L50 | 标签位里每个异常词、机制词各附一句 | 是：读者悬停的往往正是那个词；同一词只附一次 |
