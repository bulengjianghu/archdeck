# ADR-0037：选中只聚焦一跳，影响面改为显式查询

## 背景

结构视角里选中模块就按显示偏好 `impactMode` 把传递闭包投影到本层（K15）：闭包里的节点标方向与距离，两端不都在闭包里的边一律变淡。负责人在 media-web-player 上连续碰到：

1. 选中「元素族」后它自己往外的依赖边反而变淡（缺省方向是传入），与「我想看它」相反；
2. 同一次选中有时亮下游、有时亮上游，取决于面板深处一个会被记住的方向开关；
3. 影响面生效时悬停不再计算聚焦，看起来像悬停坏了；
4. 「延迟决策律」扇入 10，距离 2 就有 11 个模块，分层总览几乎整张亮，没有区分度；
5. 闭包按 import 传递，真实的变更会在稳定接口、端口处停下，图上却都画成「会波及」。

选中是最频繁的手势，意思是「我想了解这个东西」；影响面回答「改它会波及哪里」，是带任务背景的低频分析。把低频问题绑在高频手势上，每次选中都要付出读一张全局重绘图的成本。

## 裁决

### 1. 选中只做一跳聚焦，悬停叠加（L26）

选中模块：它自己、两个方向画出来的直接边与邻居照常，其余变淡。悬停：在选中的一跳之上叠加悬停对象的一跳（并集），任何时候都有效——影响面查询、边聚焦生效时也一样。聚焦变淡是共享通道（L18），结构视角与交互视角同义；运行视角按舞台显示，不变。入、出只靠线的方向与端点记号区分（S2-3），节点不加角标，实测分层总览后再定。

### 2. 影响面是面板里的一次性查询（K15b、K15c）

分段按钮「不看（缺省）/ 影响面 / 依赖面 / 两者」。查询状态 `impactQuery` 是**视图状态里的一个值**，不是显示偏好：只在结构视角、选中模块时可设；选中改变或切换视角即回到「不看」（S2-1），不进 URL、不记在本地，刷新即无。实现上不靠各处监听，而由视图状态转移在每个动作后统一判定「选中或视角变了就去掉」（工程原则 4、5：一个值、一个主语）。快捷入口只在面板（S2-4）。

「不看」时面板只列一跳（「依赖它最多 / 它依赖最多」）。

### 3. 查询缺省只看值依赖，并区分必然波及与可能波及（K15d）

查询缺省去掉只引类型（同 Y1），面板「含只引类型」临时勾选后按全部种类重算，随查询一起收回。显示偏好 `valuesOnly` 只管指标与逆稳定。

**可截断处**（S2-2：先只按端口和具名接口，稳定度阈值另议）：模块依赖 A → B 的每条文件依赖都只经 B 的**具名契约**——按名字导入、名字全是 B 子树声明的接口（含端口）或数据结构、不是子类；或只是 `export … from` 再导出（透传）。传入闭包里只走不可截断的依赖就能到达的为**必然波及**，其余为**可能波及**：外圈与标记浅一档、不加字（不占 R3 的标签位），面板标浅字「可能」，命令行与 MCP 的 `impact` 输出 `possible`。传出闭包不分。

判据不走 K18 的表面所属（入口）：media-web-player 的管线包入口归管线契约子模块，没有任何模块按 G10 得到入口，按入口判一条也截不断；按名字对声明的契约判，与「经稳定的具名接口」的原意一致，也不要求项目补 `entry`。

## 被否决

- **保留粘性方向、只把缺省改为「两者」**：仍是隐藏状态，仍把闭包绑在选中上，问题 1、2、4 都还在。
- **换选中时保留方向、对新模块重算**（S2-1 的另一选项）：查询变成又一个隐藏状态，同样的选中会因为之前点过什么而得到不同画面。
- **按 `via: port:` 的关系判截断**：关系是主张、不在依赖图上；同一对模块的依赖可能一部分经端口、一部分直接 import，按关系判会把直接 import 也截掉。端口作为声明的接口已经包含在具名契约里。
- **按 K18 表面元素（入口导出 + 声明接口）判**：需要入口，见裁决 3。

## 后果

1. 选中的含义在画布与面板上一致：「它是谁、直接和谁打交道」。与 S1（选中时布局不跳）合起来：选中是原地的一跳聚焦，不重排、不全局重绘。
2. 本地记着的 `impactMode` 旧值被忽略，不迁移。
3. 「可能波及」是启发式：数据结构算具名契约、再导出算透传是本 ADR 的取舍（来源为议，列负责人清单）；声明了却频繁变动的接口仍会被当作可截断——稳定度阈值另议。
4. 文件依赖多记一个 `reexport` 标记（K1 的提取结果），只用于本判据。
