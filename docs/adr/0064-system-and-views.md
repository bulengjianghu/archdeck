# ADR-0064：系统 | 视图——左边定主语，右边是主语的投影

- 状态：已采纳（方案 `plans/arch-desk-round22/00-ui-structure.md` 由 AI 起草，负责人 2026-11-07 对 D1–D8 全部按推荐裁决，并补充「三区页头同高、底线对齐」）；待实现（第二十二轮）
- 日期：2026-11-07
- 决策人：项目负责人
- 取代：[ADR-0062](./0062-reading-first-layout.md) 结论 1–5（顶栏拉通、选中面板抽屉、导航树浮层、理解页「事实卡 + 故事」合页、运行右栏特化）；[ADR-0061](./0061-sticky-id-card-and-explainer-shortcut.md) 的 WS-8 例外（选中自动打开图解）与身份卡粘顶；[ADR-0054](./0054-workspace-props-and-dock.md) 的三列版式、属性栏与「资料区不跟随选中」（改为两类标签）
- 修订：[ADR-0057](./0057-canvas-is-the-only-plane.md) TB-1 / TB-6 / TB-7 / TB-10 / TB-11（工具栏拆进各区页头，三条底线 → 三区页头）；[ADR-0055](./0055-explainer-is-module-info.md) 的图解内容标准（多图少文、不含事实）与显示位置；[ADR-0031](./0031-three-views-and-structure-view.md) 的呈现（三视角 → 结构 / 交互两个视角 + 场景；三种事实的分工不变）

## 背景

读一个系统只有两个动作：**定位**（有哪些部分、我在哪——地图）与**理解**（它是什么、为什么、怎么运转、可信吗——讲解）。第二十轮之后「理解」散在三处：选中面板抽屉（身份卡、五问）、辅助栏理解页（事实卡 + 故事）、运行右栏步骤节，各有一套「什么时候自动打开」的规则（WS-8 例外、250ms 稳定窗、运行视角豁免、草图编辑豁免、WS-9 自动收起）。这些规则不是需求，是「理解」没有家之后的补丁；自动开合又挤压画布、造成几何漂移，顶栏拉通与导航浮层都是为它而设。

## 决策

沿用原则 4、5「一个主语」：

1. **两部分**（D3、D8）：左边**系统** = 侧栏 + 画布，拥有主语（层次、视角、选中、场景与进度都在这里决定）；右边**视图** = 主语条 + 至多上下两组标签，是主语的纯投影——只读主语、只发意图（单击引用 = 选中）。不再有全宽顶栏，三区（侧栏、画布、视图区）各有页头，**同高 44px（含 1px 底线）、底线对齐**（负责人补充）。
2. **永远有主语**（D7）：无选中时主语是系统；打开项目即读根图解，右栏永不为空、不需要「自动打开」。
3. **两类标签**（D4）：视图标签（图解、描述、核对、时序图）按类型各一个、跟随主语，不设钉住；资料标签（对话、源码、设计说明、ADR）不跟随。图解常驻；有场景时时序图常驻；常驻标签可拖不可关。
4. **四个视图标签各答一问**：图解 = 怎么回事（AI 讲解，多图少文、不含事实，D6）；描述 = 被声明成什么（架构台渲染的事实，原事实卡、五问卡、步骤节）；核对 = 可信吗、健康吗（核对卡，ADR-0059）；时序图 = 按时间怎么走。
5. **两个视角 + 场景**（D1）：视角只有结构、交互；回放 = 交互视角 + 选中一个场景；场景列表进侧栏。旧地址的运行视角重定向为交互 + 该场景。
6. **侧栏停靠**（D2）：模块 / 场景 / 改动三页，可收起、可拖宽，按本机记住；≥ 1440 缺省展开；只由人开合。
7. **缺省排布由情境推出**，人改过按情境分别本机记住；视图区可整体收起（D5）。
8. **选中不改变任何区域的宽度**：漂移的根因（自动开合）消失，为它而设的机制删除。

规则编号 LY-1–LY-16（02 §2.29）；作废与修订的旧规则在 02 原处保留编号并注明去向。

## 选项

| 备选 | 不选的理由 |
|---|---|
| 右栏标签按主语开（每选一个模块开一个标签） | 堆积；对比需求是「同一主语不同角度」而不是「不同主语」；会把 ADR-0012 删掉的钉住带回来 |
| 保留抽屉，只在辅助栏加标签 | 理解仍分两处，「自动打开」规则不会消失 |
| 侧栏继续做浮层 | 盖住画布左缘；模块树 / 场景 / 改动是常用导航，不是临时面板；挤压只在自动开合时才有害 |
| 运行保留为第三视角 | 运行与交互画同一张图，差别只是挑出一个场景的有序子集；少一次心智切换 |

## 后果

- 删除：选中面板抽屉、导航树浮层、全宽顶栏、理解页合页、运行右栏特化、选中自动打开图解 / 理解页（WS-8 例外与 250ms 稳定窗）、WS-9、TB-1 让位、DL-4 缺省主语表（由 LY-11 情境排布取代）、DL-20 草图态抽屉规则。
- 工作区状态改写为「两组 × 两类标签」的一个值与纯转移（`transition/workspace.ts`），本机记忆经同步适配器；属性栏开关、资料区显隐、焦点组从工作区状态删除。
- 原 PC-*（三卡内容）、V6（运行信息）、EX-*（图解查找、引用、过期）的内容规则保留，家变为描述 / 核对 / 图解标签（LY-13）。
- E2E 再一次大面积改写：先把选择器收敛到语义锚点（`data-region`、`data-view-tab`），再动版式。

## 第 3 版修订（负责人 2026-11-08 走查）

实现落地后负责人走查，提出 6 处界面问题；协调者按问题做了原型第 3 版（`plans/arch-desk-round22/proto-system-views.html`），负责人同意按它落地。结论不改本 ADR 的决定（左边定主语、右边是投影），只改投影的形状：

1. **底色按区域性质分**（LY-2a）：竖栏、侧栏、视图区与各区页头是面板底，画布正文是唯一下沉的台面。理由：原来侧栏与画布同底、视图区另一种底，三区的「性质」（导航 / 地图 / 读物）没有在底色上分开。全局配色不改，暖灰另议。
2. **页头一条线**（LY-2）：竖栏顶格与三区页头的底线同色同 y、首尾相接；区与区之间只画 1px 线，拖拽命中区在线两侧透明扩展。原来 5px 白色分隔条让线在交界处断开。
3. **视图标签是文字**（LY-8、LY-13e）：选中为深色字加 2px 下划线，标签栏不画底线；图解的 ↑ ↓ 并入内容顶部随内容滚动。视图区只剩主语条那一条横线。
4. **视图标签全部常驻**（LY-9、LY-9b）：视图标签每类一个、跟随主语，关掉没有收益；「+」只开资料标签。「核对」名带结论「核对 ⚠N」，不点开也知道要不要看。
5. **场景排布与进度**（LY-8、LY-11、R15a、R16a）：时序图是第三类标签「情境标签」——跟随场景、不跟随主语，名带进度；场景缺省上组只有时序图、下组是跟随主语的三个视图标签。场景中选中模块只换主语、不改进度：时序图保留当前步、突出这个模块的泳道与消息，画布保留当前路径。只有选中步骤或 ← → 才改进度。这修订了 R15「只有被选中的那一个对象用选中样式」——一个主语的不变式（CLAUDE.md §2 第 5 条）不变：主语仍唯一，进度是场景的状态，不是第二个主语。
6. **侧栏竖栏**（LY-3、LY-4、LY-4d）：最左 44px 竖栏放侧栏开关与三页图标，侧栏收起时它还在；画布页头的侧栏开关移到竖栏顶格。侧栏页内只有页名与「筛选 ▾」，原来平铺的树 / 排序 / 只看需复核与范围 / 类别 / 发起者都收进弹层。参照 Claude Code 桌面版的活动栏。

实现中补的细化（02 §2.29 末表，来源「议」）：LY-4d 的计数口径与「场景 ▾」下拉共用一份筛选、LY-9b 系统 / 层两张卡相加、LY-10d 视图区宽度按竖栏右边那块算、LY-11d 草图排布下组补核对、R16a 的滚动口径。实现与验收见 `plans/arch-desk-round22/21-patch-report.md`。
