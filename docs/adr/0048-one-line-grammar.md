# ADR-0048：线的语法收敛为一套——常显的线都进布局并被测量，时间耦合按需显示

- 状态：已采纳，已实现（第十四轮波 2：F12、F7）；两套车道的代码合并为后续
- 日期：2026-10-28
- 决策人：项目负责人（2026-10-28「按推荐定稿」：F12；F7 按需显示——选中或悬停时临时画耦合对，常显的只剩面板清单与计数）；起草：第十四轮主线会话
- 关联：[ADR-0039](./0039-line-clarity-and-actors-left.md)（L30–L33、O14–O16）、[ADR-0035](./0035-line-grammar.md)（波浪线是线型的唯一例外）、[ADR-0040](./0040-bundle-trunks.md)（不在 elk 之后改写走线）

## 背景

线的身份可辨、不互压，只有在所有常显的线都经过同一个分轨器、都被检查器量过时才有保证（seeing 不变式 8）。盘点：代码依赖叠加线（K9，交互视角缺省开启）三项目共 69 条，其中 66 条一端是边界节点，全部画成不参与布局的曲线、从不被 L30 测量；组装叠加线同样；时间耦合波浪线常驻、不进布局。

## 裁决

1. **规则**（定）：任何常显的线都必须进入布局与分轨，并在它出现的视角里由 L30 测量；否则只能临时出现（L44①）。
2. **代码依赖叠加线**（议）：两端都在本层的常显，走并集布局里同一对节点的束的走线，框外边分轨时只占不动地避开它，纳入交互视角的 L30 测量；一端是边界节点的同框外的交互边（L4）只在聚焦一端或选中时画，与此刻的框外边一起分轨，画布角计数。对照实验：把框外叠加线与框外边一起常显分轨，h5p 的旧线重合 59 → 82；先走框外边、叠加线随后分轨（旧线不动），叠加线与同端点的交互边互压，h5p 重合 59 → 126、箭头叠 1 → 11——两种「常显」都违反只降不升，故按 L4 临时出现。
3. **时间耦合**（定，F7）：按需显示，常显的只剩画布角计数与面板清单。
4. **一套车道语法**（读法：定；代码合并：议，后续）：带间空隙的轨道（O14、O15）是走廊分轨（L32）的特化——同轨距、同障碍口径、同标签避让、同一个分轨器收尾；读者读到的是同一种线。把 O15 的空隙轨道次序改写成分轨器的走廊约束只降维护成本、不改画面，L30 风险需另行实测，留作后续。

## 实测

交互视角 L30（三项目）：h5p 59/1/3/0/7/0、h5player 93/1/2/1/18/0、media 23/0/7/0/5/0，与本轮 F1 后一致（新纳入测量的 3 条本层叠加线没有新增问题）；结构视角不变。

## 后果

- h5player 交互视角静息态不再有 24 条从框外进来的叠加曲线；它们的计数在画布角，聚焦一端即出现、且与框外边一起分轨。
