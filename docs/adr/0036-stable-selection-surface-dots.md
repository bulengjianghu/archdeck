# ADR-0036：选中不跳——定尺寸点阵端口

- 状态：已采纳，待实现（第十一轮 S1）
- 日期：2026-10-27
- 决策人：项目负责人（2026-10-27：「方案同意，写进第 11 轮」）；起草：第十一轮 S1 方案会话
- 关联：[ADR-0031](./0031-three-views-and-structure-view.md)（V12：切换视角节点不动）、[ADR-0032](./0032-module-surface-and-carrier-chain.md)（C6 表面展开、D7 交互束按表面散开）、[ADR-0033](./0033-handles.md)（L20b 元素按子模块分组）、[ADR-0034](./0034-callback-and-reading-lines.md)（L25 悬停边的样式）；修订 L20②④、L20a②③⑥、L20b 画法、L23、L23a②，V12 补注；需求 C-28、新增 C-33

## 背景

普通层次上选中两个不同的模块，整层布局会变，看起来「跳一下」。这是第八轮的规则而不是缺陷：L20② 规定选中模块即展开它的表面，元素作为 elk 端口排在入边一侧、节点随元素数加宽，束散开为元素级边，布局同步监听到 `links` 变化就让 elk 整层重排；L20② 原文写着「展开改变节点尺寸，本层重新布局，等同下钻，不算违反 V12」。

读图靠心理地图（位置记忆）。选中是一次浏览会话里的临时指针，不是被描述系统的属性，不该让位置变化。端口名是深入信息，应该按需给出；画布上该留下的是「有几个把手、哪些线落在同一个把手上」。

2026-10-27 在 media-web-player 上实测「缺省全部展开」（36 个普通层次）：管线族 Provider 交叉 18 → 115、面积 ×3.1，视图状态层面积 ×2.6，模型层、接入层、播放器 Kit 都明显变差；噪声来自节点变宽（面积、绕远、字读不清）和束散开成元素级边（交叉增加）。另见元素名互相重叠、被截断。

## 裁决

### 1. 位置与展开无关

节点的位置与尺寸只按收起态计算。展开只改两样：节点上的端口点，以及接到元素的边的终点（从节点本体换到端口点）后重新走线。选中、取消选中、换选中、打开「总是展开表面」，节点都不动。

原则：**位置只由描述和持久的显示偏好决定，选中与悬停只改高亮、端口与面板。** V12（切换视角节点不动）的理由同样适用于选中；第八轮「等同下钻」的说法作废。

### 2. 定尺寸点阵端口

展开时节点尺寸不变。入边一侧排一排端口点，**不写元素名**；点的形状按种类区分（端口 ◇、操作 ●、类型 ○、数据 ■，沿用 L20⑤）。上限沿用 `SURFACE_PORT_CAP` = 16，第 17 个起收进一个「+N」，清单在面板「表面」一节。只排一排：elk 的端口在一侧只能排成一条线，两排会带来走线异常。端口这一端**不画箭头**，点本身就是终点记号；方向由线型和发起方一端表达，免得十几个箭头挤在一起。

### 3. 子模块组标（保留 L20b）

点按所属子模块分组，组间留间隙，组首写子模块短名；本体那一组在最后，不写组名。不悬停也能读出「落在哪个子模块」（第九轮：普通层次答「落在哪几个把手、属于哪块」），具体元素名留到悬停。组名放不下时截短，悬停给全名。

### 4. 悬停与单击（不新增选中种类）

- 悬停端口点：高亮落在这个点上的边及其发起方（样式同 L25 悬停边）；提示框写「名字 · 种类 · 所属子模块 · 扇入（使用它的模块）」。
- 单击端口点：按 L20④ 现有行为选中所属模块，把面板「表面」一节滚到这个元素；面板里这一行与画布高亮联动。
- V2「不新增选中种类」不动。把元素做成选中种类（进 URL、可分享、影响面算到元素级）要改 V2 和原则 5，另立 ADR，等本方案用下来确有需要再提。

### 5. 交互束同样落到点阵

展开接收方时，交互束按 `interface` 散开到对应的端口点，没写接口的接到节点本体（L23 不变）；运行视角的舞台高亮落到端口点。

### 不变的

触发规则（选中模块展开它；选中交互或视图边展开接收方、只散开发起方一侧；选中束不展开）；「总是展开表面」仍是本地偏好、缺省关，落地后用同一组层次重测，再决定要不要更积极地推荐；分层总览不展开。

### 被否决

- 按关系多少用阈值决定展开：代价最大的枢纽反而被展开，阈值本身也是任意的。
- 用节点大小表达复杂度：面积是弱通道，而且节点大小量的是表面宽度 W，不是关系多少。
- 缺省全部展开：实测噪声过大（见背景）。

## 后果

1. 布局分两步：节点位置与不接元素的边的走线取收起态的布局（同一份缓存，换选中零重排）；展开由一个纯函数在固定的节点上排点并重新走线（L20a②），不再调 elk。
2. 接到点的边沿它所在束的收起态走线走到节点前，在节点外的扇出线上横到各自的点；束不再在整条路径上散开，交叉主要集中在节点前的一小段。
3. 第八轮 T2-9「新展开的节点适应视口」作废：节点不动，没有要适应的。
4. 自左向右布局的节点入边一侧只有节点高度那么长，放得下的点比 16 少，其余计入「+N」（L20a②）。
5. 端口一端不画箭头要改画布边组件（`DepEdge`、`RouteEdge`）的终点记号，与第十一轮 R3「线的语法」的改动面重叠，合并时以 R3 的画法为准、保留「接到端口点不画箭头」。
