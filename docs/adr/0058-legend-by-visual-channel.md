# ADR-0058：图例按视觉通道组织——准入三问

- 状态：已采纳（负责人 2026-11-02 第十八轮走查，五点裁决全按推荐）；已实现（走查分支 `round18/walkthrough`）；标「议」的细则待裁（见末节）
- 日期：2026-11-02
- 决策人：项目负责人
- 修订：[ADR-0056](./0056-interactive-legend.md)（图例的组结构、「临时可见」小节、组折叠）；ADR-0031 裁决 D 的「共享通道三组同文」改为「三处同位同文」
- 关联：需求 W-2、W-10；规则 L18、L19（改写）、L45（修订）、L47（修订）、L48（修订）、L50、L51（扩展）、L16（示意文字）；原则 C1、C5、C6；ADR-0041 的「词表准入四问」

## 背景

第十八轮走查第一条：图例本来是帮人读图的，现在读图例本身就要花注意力。截图那一层的交互视角图例有 6 个组、约 30 行，其中 7 行换成两三行的长句。对照图例的目的（读者看到画布上一个记号、不知道意思时查一下；成本是注意力，收益是少读错），有三类浪费：

1. **同一记号讲两三遍**：线宽三档（关系 › 粗细；共享 › 线宽）、虚线 = 依赖（共享；代码事实 › 未解释；组装）、违规（代码事实 › 违规；共享 › 红晕）、环编号、演化、标签位格式、同步 / 异步，各出现在两到三处。
2. **画布上已经写了字，图例又列一遍**：机制词（跨进程……）、两段示例（×5 · 未证实 2）、未证实 / 违规 / 未解释、组装根、混合——画布 pill 就是这个词，悬停还有释义（L50）；「机制 › 直接」是没有记号的缺省态。
3. **讲解混进解码**：类型行后的定义（「= 要结果、无副作用，后果归调用方」）、开关行后的说明与统计、三个「临时可见」小节的行为描述（「……时画出」「清单在面板……」）。

组织方式也错了：关系 / 节点 / 代码事实 / 组装 / 演化 / 共享是工具内部的模块划分，读者面对画布问的是「这条线的颜色、粗细、箭头、线型是什么意思，这个框、角标是什么」；「共享 · 三个视角同义」更是工具的架构事实（L18）泄漏到了界面上。

## 结论

### 0. 准入三问（L47 修订）

一行要进图例正文，必须全过三问（对应 ADR-0041 给标签词定的准入四问）：

1. **这个记号在画布上自己会说话吗？** 写了字的 pill、带数字的角标，看一眼就懂，悬停有释义（L50）。会说话的不列。
2. **现在画面上有吗？** 悬停 / 选中 / 回放才出现的记号此刻不在画面上，出现时悬停释义在用到的地方解码。不在画面上的不进正文，归脚注。
3. **这一行是在解码（记号 → 含义）还是在讲解（概念定义、标签格式、什么时候出现、去哪个面板看）？** 讲解进帮助（L51）或悬停，正文只解码。

过了三问的行：一行 = 一个记号 + 一个短语，不换行（卡宽 270px、文字列约 15 个汉字）。

### 1. 正文按视觉通道分节，不按数据来源分组（L19 改写）

| 节 | 行 | 视角 |
|---|---|---|
| **线** | 颜色 = 关系类型（开关行，L45）；粗细 = 条数（`WidthRow`，三视角同一行同一句）；箭头 = 同步 / 异步、插座 = 经端口（有才列）；线型 = 实线交互 / 虚线依赖（画面有虚线才列） | 交互、运行（只读） |
| **线** | 形态 = 端点记号（子类、组装、端口实现、使用）；醒目度 = 深色加宽例外 / 中灰骨架；只引类型（开关行、带收起条数）；粗细 | 结构 |
| **节点** | 模块 · 可下钻 · 目标态 / 外部（一行） | 三视角 |
| **规则** | 红晕 = 违规、↻N = 本层的环（有才列，整节可不出现） | 结构 |
| **指标** | 角标「入 · 出」、色条 = 不稳定度三档（口径在悬停） | 结构 |
| **叠加** | 四个开关各一行：代码事实、组装（交互）、演化热度（带口径）、时间耦合；开着时只列非文字记号：红晕 = 违规、↻N = 环、菱形虚线 = 组装、三档角标 = 热度 | 交互、结构 |
| **脚注** | 「▸ 悬停 / 选中时另有 N 种记号」，缺省折叠（见 3） | 三视角 |

节只是一行标题，不折叠；「怎么读一条线」的「?」在「线」一节标题旁（L51）。共享通道（L18）不再有自己的一组：线宽、线型在「线」，红晕、环在「规则」或代码事实下，选中、变淡、波浪线在脚注——三个视角同一位置、同一句话（文字仍只在 `labels.ts` 一份，C1）。

### 2. 不列的（过不了三问）

| 项 | 去处 |
|---|---|
| 类型行的定义文字 | 行悬停（已有）+ 帮助「读一条线」新增一段四类定义 |
| 机制 › 直接 | 删（缺省态，ADR-0041「缺省值不写」） |
| 标签 › 机制词、两段示例、「混合」 | 删；词在线上，悬停有释义；格式与词表在帮助 |
| 代码事实下的 未证实 / 违规 / 未解释 三行、组装根 | 删；只留非文字记号 |
| 结构视角的 交互使用 / 值使用 两行 | 删；画布上与另一档同画，没有记号可解码 |
| 束的一句说明、规则叠加的「允许不加标记」、指标的公式与阈值 | 帮助 / 悬停 / 缺省态不列 |
| 开关行后的说明与统计 | 悬停（`TOGGLE_HINT`，已有） |
| 「共享 · 三个视角同义」整组 | 取消；行按通道归位；选中 / 变淡两行进脚注 |

删掉的每个字记号，画布上悬停必须有释义——线与线上标签由 L50 覆盖；节点角标（组装根、表面 W、入 · 出、热度）各自带 title。

### 3. 临时记号归一个缺省折叠的脚注（L47 修订）

静息态不出现、悬停 / 选中 / 回放才出现的记号，整张图例只收在一个脚注「▸ 悬停 / 选中时另有 N 种记号」里（运行视角为「回放 / 选中时」），缺省折叠、展开才列（`TempLegend`）。条目按视角：交互——只在边界边 / 核心跨层边上的类型、承载缺段（代码事实开时）、波浪线（时间耦合开时）；结构——选中束承载的交互实线、表面元素四类与「+N」、收起与例外的计数（跨界折叠、例外照画、环按组、另直连）、表面 W、越过入口、逆稳定、共用件折叠、波浪线；运行——回放的记号。选中与变淡三视角都列、排最后。取代 ADR-0056 §3 各组尾部常列的「临时可见」小节。

### 4. 取消组级折叠（L48 修订）

正文只剩十几行，整卡的收放（按项目记在本机）够用；`useDisplayPrefs` 不再记各组折叠，运行视角「缺省只展开回放」作废。

### 5. 帮助承接讲解（L51 扩展）

「读一条线」一节在三问之后加一段四类关系的一句定义（`RELATION_TYPE_HINTS`，与行悬停同文）；机制九词、两段标签位格式本就在这一节。

### 6. 同一套规则三个视角都适用

结构视角的图例同样过三问：正文只留端点记号 = 形态、明度 = 醒目度、只引类型、粗细、红晕 = 违规、入 · 出与色条；其余（折叠计数、表面、束、逆稳定、共用件）进脚注或帮助。运行视角正文只有线（只读）与节点，回放的记号全在脚注。

## 否决的方案

| 方案 | 为什么不 |
|---|---|
| 保留类型行的定义，只缩短 | 任何缩写都是第三种措辞（违反 C1）；定义是学一次的内容，属于帮助（ADR-0056 §4 已定） |
| 「临时可见」仍按组放、只折叠 | 三个小节三个折叠控件；临时记号本就不在画面上，一个脚注足够 |
| 保留「共享」组、只去重 | 读者不需要知道哪些通道跨视角共享；L18 的约束落在词表层面即可 |
| 每节仍可折叠 | 正文已短到一屏，折叠状态是多出来的记忆负担 |

## 后果

- 截图那一层（交互视角）从约 30 行（7 行换行）降到 15 行、不换行；E2E 行数基线从 交互 33 / 结构 42 / 运行 33 降到 20 / 26 / 18（脚注展开量）。
- 组件：`Legend.vue` 重排；`RelationLegend`、`StructureLegend`、`RuleLegend`、`MetricLegend` 改写；新增 `OverlayLegend`（四个叠加开关）、`TempLegend`（脚注）、`WidthRow`（线宽行）；删除 `SharedLegend`、`FactsLegend`、`AssemblyLegend`、`EvolutionLegend`、`ReplayLegend`、`DisplayGroup`。出现集合（`state/desk/legend`）不变。
- 文字：`labels.ts` 只改 `DEP_FORM_HINT` 四句（去掉冗余的「虚线 +」，示意线本身就是虚的）、删 `SHARED_CHANNELS_TITLE`、加 `SHARED_TEXT` 按键取句；其余一字不改，只是不在图例里渲染。
- 画布上写了字的记号从图例删掉后，第一次读图的人要多一步（悬停或点「?」）——以帮助与悬停释义承接。

## 待裁（「议」规则）

- 脚注的折叠态不记在本机（每次打开都折着）；换层次、换视角时保持当前开合。
- 结构视角「收起与例外」四条计数行放脚注而不是删除（它们描述的是没画出来的东西，仍有查阅价值）。
- 热度行后面的口径（· 修改 / 缺陷）保留在行上（是解读角标必需的状态，不是说明）。
