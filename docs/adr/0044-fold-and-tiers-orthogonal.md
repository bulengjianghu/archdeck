# ADR-0044：折叠与分层正交；组织判断三态都说出来

- 日期：2026-10-28
- 决策人：项目负责人（2026-10-28「按推荐定稿」：F1「+N」先按推荐标跨度、出截图复核；F5 搭车 F1）；起草：第十四轮主线会话

## 背景

`present` 有 16 个子模块，按 O8 折叠后只剩 4 个核心，L28④「有核心、其余折叠的层次只让核心分层」使它永远够不到层带门槛（7 个节点、3 层）；层号随折叠变化。布局依赖了易变的视图状态（折叠）：折叠一变，分层就变或消失。

## 裁决

1. **层号对全集算**（定）：层号、环组、层带门槛按「+N」展开后的全部子模块计算；折叠只决定画多少个节点（L39①）。折叠回答「看多少」（少），分层回答「怎么读」（位置即方向），两者正交。
2. **「+N」标跨度**（定，先按推荐，出图复核）：占位块放在成员中最上的一层，写「折叠 N · 第 X–Y 层」。放最上一层（议）：成员多半依赖下面的层，占位块的出边大多朝下；放最下一层则出边大多朝上、制造假的「向上」。备选「只按最低层、不标跨度」保留给复核。
3. **展开即解压**：成员落到已算好的层号，层与层带不重排。
4. **F5 组织判断三态**（L40）：层（画布角「层 · 算出」）、拆（「+N」跨 ≥ 3 层时在占位块上提示「该标核心或该拆」；有交互没依赖照 K21③）、平铺（子模块彼此既无依赖也无交互时画布角明说）。三态都说出来，「没想过」与「平铺即诚实」分得开。

## 后果

- 复杂模块（如 `present`）在折叠状态下也有层带，是 F8「一套读法」的前提。
- 「+N」的跨度成为组织判断的信号；跨度门槛 3 层与文案为「议」，出图复核。
- 层带门槛按全集判定后，折叠的层次也可能出层带：节点少而层多时层带里只有「+N」与核心，这是诚实的（层在那里，只是没画全）。
