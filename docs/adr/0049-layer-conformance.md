# ADR-0049：结构符合性校验——已确认的层与实算比对

- 状态：已采纳，已实现（第十四轮波 3：F3）
- 日期：2026-10-28
- 决策人：项目负责人（2026-10-28「按推荐定稿」：F3 info 起步、只进返工清单，不进画布；阈值实现时实测后报；无代码事实的版本维持按边排 + 画布角说明）；起草：第十四轮主线会话
- 关联：[ADR-0038](./0038-tiers-by-dependency.md)（L28 的算法）、[ADR-0045](./0045-one-layer-grammar.md)（只有已确认的层接受校验）、ADR-0023（确认层 Z 系列）

## 背景

声明的层只校验「允许依赖谁」（`mayDependOn`），不校验「声称的结构」是否还成立；原则写下来之后会随代码漂移。

## 裁决

1. **比对**（定）：分层总览里按层之间的值依赖用 L28 的算法实算层号，与声明的 `order` 比对；成环与倒置都是漂移（K24）。
2. **只对已确认的层、只进返工清单**（定）：info，类别「层的符合性」；不进画布、不进门禁。未确认的层还只是主张（Z3），不报。
3. **阈值**（议）：任何一处倒置或成环都报。实测（三项目全部声明层，不看确认状态）：

| 项目 | 漂移 |
|---|---|
| h5p-arch-desk | 倒置 1：声明「视图状态层」在「接入层」之上，实算在它之下 |
| h5player | 成环 1：Infrastructure ⇄ Application |
| media-web-player | 倒置 1：声明「管线契约与共用律」在「管线族 Provider」之上，实算在它之下 |

   三处都与本轮 K22 扩到声明的层后新出的「向上」提示（ADR-0045）同源，噪音低，故不设更宽的阈值。三个项目的层目前都未确认（`已确认 0`），返工清单现在没有这一类；确认后即出现。
4. **无代码事实**（定）：不比对，维持按边排与画布角说明。

## 后果

- 原则不会悄悄过期：一层被确认后，它与代码的偏离就进返工清单。
- 与第十五轮 F6（状态所有权）的「声明与实算」比对共用同一机制（layerDrift 的形状）。
