# ADR-0055：图解是模块的一项信息

- 状态：已采纳（负责人 2026-10-30 审核第十七轮需求 R5，D5）；第十七轮 W5 实现中，标「议」的细则待裁（见末节）
- 日期：2026-10-30
- 决策人：项目负责人
- 关联：需求 R5（第十七轮）、W-4；规则 M32、EX-1–EX-10（新增），WS-4、PC-6、PC-9（修订）；原则 C1、C2、C5；[ADR-0023](./0023-sketch-reviewed-and-evolution.md)（确认指纹 Z2）、[ADR-0053](./0053-panel-five-questions-and-contract.md)（summary、invariants）、[ADR-0054](./0054-workspace-props-and-dock.md)（资料区）

## 背景

架构台回答「结构」和「行为」：有哪些模块、谁连谁、一个场景怎么走。它不擅长回答「原理」：这个机制怎么运转、为什么这样切分。后者适合一张示意图加几段话——AI 生成的 HTML 讲解（artifacts）做得很好。但单独的讲解文档有两个老问题：

1. **重复与冲突**：讲解里抄一遍职责和不变式，描述改了，讲解就和它不一致，而且没人知道。
2. **过期**：写完就开始过期，没有信号告诉读者「这份是基于旧描述写的」。

分析见第十七轮计划 `00-look-panels.md` §3：架构台是地图（完整、实时、可查询），图解是导游书（选一条路线讲明白）；心智模型两者都要。

## 结论

### 1. 图解挂在模块上，不是独立的文档集（EX-1、M32）

- 一个模块至多一份图解，存放在 `model/<项目>/explainers/<模块 ID>.html`，或由模块的 `explainer:` 字段指定。系统根的图解即项目总览。
- 没有图解目录，只能从模块进入：属性栏相关资料卡、画布节点上的 ▣、图解之间的链接与 ↑ ↓ 导航（由模块树推出，不另建图解之间的关系）。
- 跨多个模块的机制挂在它们的最近共同父模块上——解释这个机制的原则本来就属于父模块（与 ADR-0052 的原则归属同理）。

### 2. 引用而不抄写（EX-2、EX-8）

图解提到另一个模块时写 `data-arch="<模块 ID>"`；要引用描述时再加 `data-field="summary"` 或 `"invariants"`，由架构台在显示时填入原文。描述是唯一来源，图解里没有可以和描述不一致的副本。`lint:model` 查指向是否存在、正文是否抄写了某个模块的 summary 或不变式原文。

### 3. 父子分工（EX-8、EX-10）

父模块的图解只讲子模块之间怎么配合、为什么这样切分，把子模块当黑盒；子模块的图解只讲自己内部。父模块的图解链到孙模块即为越级（`explainer.too-deep`）。生成自上而下。

### 4. 过期按依赖范围算，复用确认指纹（EX-6、EX-7、EX-9）

依据 = 本模块的描述（Z2 的确认摘要 + summary + invariants）+ 子模块的 summary / invariants + 子模块之间的关系。按项记 8 位指纹（同 Z2 的算法），所以能说出「N 处改动」并列出是哪几处；子模块内部改动不会让父模块的图解过期，子模块的对外承诺变了才会。依据写在图解的 `<meta name="arch-basis">` 里，由 `arch explainer --write` 刷新。

### 5. 在资料区以沙箱 iframe 显示（EX-3、EX-4、EX-5）

图解是资料区的一种标签（预览、固定、分屏都照 WS-5、WS-6）。iframe 只给 `allow-scripts`、不给 same-origin，并注入禁止网络请求的 CSP；架构台在显示前填好引用、注入一段只发 postMessage 的桥接脚本。父页只接受来源是那个 iframe 窗口的消息。点模块链接即在画布上选中它（属性栏随之变化），资料区不动（WS-8）。

## 否决的方案

| 方案 | 否决理由 |
|---|---|
| 图解作为独立文档目录，另设浏览入口 | 与模块脱钩后既找不到也没人维护；R5.1 要求「只能从模块进入」 |
| 图解里直接写职责、不变式的文字 | 描述一改就冲突，且不可检测（C1） |
| 只记一个整体指纹 | 只能说「过期了」，说不出改了哪几处，读者无从判断还能不能信 |
| iframe 给 same-origin 以便父页直接读写 DOM | 与 allow-scripts 同给等于没有沙箱；用 postMessage 加来源校验足够 |
| 依据包括子模块的全部描述 | 子模块内部一改父图解就过期，过期信号失去意义 |
