# ADR-0010：副栏标题栏合一、时序图对齐、悬停临时显示静态关系

- 状态：已采纳
- 日期：2026-10-21
- 决策人：项目负责人
- 关联：需求 W-4、D-2、D-17；领域模型 §2（V10）；ADR-0008、ADR-0009

## 背景

ADR-0009 上线后，负责人提出三个问题：

1. **上下布局时泳道没对齐**：消息区比泳道头更宽，越往右偏得越多。原因是消息区的 SVG 设了 `min-width: 100%`。副栏比时序图宽时，SVG 被拉满并按比例居中放大；泳道头没有被拉伸。
2. **两栏叠在一起不美观**：副栏标题栏（收起、页签、方向切换）下面，还有一条时序图信息条（层次名、不可见提示、「定位」）。
3. **静态关系隐藏时，悬停模块要不要显示它的静态边**。

## 结论

### 1. 时序图三块按同一宽度从左起排

泳道头、消息区、底部泳道头都按时序图自身宽度从左边起排，不拉伸。副栏比时序图宽时，右侧空出的部分只铺背景（D-2）。

### 2. 副栏标题栏合成一栏（W-4）

- 一栏从左到右依次是：收起、页签「时序图 / 源代码」、当前层次名与「本层不可见」提示、「定位」、方向切换。
- 层次名、不可见提示和「定位」只在「时序图」页签出现。
- 删除时序图自己的信息条。「定位」由副栏调用时序图暴露的方法，不进视图状态。

### 3. 悬停临时显示静态关系（新增 V10）

| 方案 | 结论 |
|---|---|
| **悬停临时淡显**：「隐藏」模式下悬停一个可见节点，它的全部静态边及对端节点以淡显样式出现，移开即收回 | **采纳** |
| 悬停不显示，只靠单击钉住 +「在画布上显示」（V9） | 未选：多一步操作，与结构视角的悬停习惯（C-9）不一致 |

理由如下：

- 「默认隐藏」是为了减少常驻噪音。悬停是用户主动探查，正是「需要时再看」。
- 这是画布上的高亮，不是弹出框，与 ADR-0009 取消的悬停弹出不同。

细则：

- 「淡显」模式下悬停，该节点的静态边提升为正常显示。「全显」模式不变。
- 不改焦点，不进 URL，布局不变。
- 隐藏的节点不渲染，悬停只发生在可见节点上，不会层层展开。

## 后果

需求 W-4、D-2、D-17，领域规则新增 V10，工作台专题按最终态改写。本项目的架构描述随代码更新。
