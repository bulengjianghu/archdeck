# ADR-0054：工作区布局——属性与资料分离，参照 Claude Code

- 状态：已采纳（负责人 2026-10-30 审核第十七轮需求 R2，D4、D8）；第十七轮 W2 已实现，标「议」的细则待裁（见末节）
- 日期：2026-10-30
- 决策人：项目负责人
- 部分取代：[ADR-0010](./0010-aside-bar-and-hover-reveal.md) 结论 2（副栏标题栏合一、方向切换）；[ADR-0006](./0006-workbench-navigation.md) 的分屏方向可选（资料区固定为右侧一列）
- 关联：需求 W-1、W-2、W-4、R2（第十七轮）；规则 WS-1–WS-10、G15（改写）、V2、V7；原则 C5（CLAUDE.md §2 第 10 条）

## 背景

第十六轮之后画布基本达标，画布周围的布局成了建立心智模型的瓶颈：

1. **两类信息挤在一处**。属性面板（「这个对象是什么」）跟着选中走、永远只有一份、窄而长；时序图、源代码（「我正在读的这份东西」）跟着阅读走、会有多份要对照、宽。旧布局把后者塞进画布区的「副栏」，靠页签切换，栏宽随内容来回跳，也不能同时开两份。
2. **副栏跟着选中跳**。G15 让「移动进度」把副栏切回时序图，读源代码时单步一下就被打断。
3. **顶栏横跨全宽**，属性面板与副栏都在它下面，画布能用的高度与宽度都被压缩；运行视角打开场景后画布常常不足 500px。

负责人要求信息组织参照 Claude Code 桌面版（原则 C5）：工具栏只属于工作区；属性是固定宽度的卡片，按空间并排或悬浮；文档是多标签、可分屏、可关闭的资料区；预览标签不堆积。原型 `proto-dock-v3.html`（第十七轮计划目录）为交互定稿。

## 结论

### 1. 三列：导航 | 工作列 | 资料区（WS-1）

```text
┌导航┐┌ 工作列 ─────────────────────────────────────────┐┌ 资料区 ───────────────┐
│    ││ 工具栏：导航 · 版本 · 视角 · 面包屑 … ▤ 属性 ▣ 资料 ││ [时序图] [源代码 ×] ⊟ ✕│
│    ││ 画布                          │ 属性栏 330px      ││  内容                  │
│    ││                               │（并排或悬浮）     │├────────────────────────┤
│    ││ 回放控制条                                       ││ [源代码 ×]（下组）     │
└────┘└──────────────────────────────────────────────────┘└────────────────────────┘
```

工具栏只属于工作列；资料区是一列从顶到底，每组的标签栏在第一行、与工具栏同高。导航树从顶到底在最左。

### 2. 属性栏：固定宽度、跟随选中、按空间并排或悬浮（WS-2、WS-3）

- 宽 330px，内容就是选中对象的面板（V2），只跟选中走。
- 是否并排**由宽度推出，不存状态**：工作列放下属性栏后画布还能留 ≥ 620px 就并排，否则悬浮在画布右侧（阴影卡片，不挤压画布）。打开资料区、改窗口大小时自动切换，工具栏「▤ 属性」旁标出「并排 / 悬浮」。
- 悬浮时画布的「适应」只用没被卡片盖住的部分，画布右侧的浮层让出卡片宽度（议，见末节）。
- 开关是工作区状态的一个值：「▤ 属性」与卡片右上角 × 切换；换选中不会把关掉的属性栏再打开。

### 3. 资料区：多标签、预览标签、最多两组、不跟随选中（WS-4–WS-8）

- 资料是标签：时序图、源代码，以及第十七轮 W5 的图解。每份资料一个键，同一份只开一个标签。
- **预览标签**（VS Code / Claude Code 的做法）：单击打开的是预览（标题斜体），下一次单击打开替换它；双击打开、或双击标签，固定下来。一组至多一个预览标签。
- **分屏**：「⊟ 分屏」把资料区分成上下两组，最多两组；新打开的资料进入获得焦点的组。
- **不跟随选中**：选中、悬停、移动进度都不改资料区。打开资料的只有明确的「打开」动作——打开场景（时序图）、选中文件或面板里的「预览」（源代码）、相关资料（W3 起）。这把 G15 的「指向」规则改成「打开资料」语义。
- 资料区从无到有时自动收起导航树，把宽度让给画布；「专注」一键收起导航与属性栏（WS-9）。
- 时序图的「定位」「图例」与本层不可见提示，从副栏标题栏移到时序图标签内容区的顶部（WS-10）。

### 4. 状态归属：工作区状态是视图状态层的一个值

按 CLAUDE.md §2 第 3 条判别：换一个前端（命令行、AI 查询），「哪些资料开着、属性栏开没开」都不需要——它们是一次浏览会话的规则，归**视图状态层**。按第 4 条：

- `WorkspaceState`（标签、预览、分组、焦点组、资料区显隐、属性栏开关）是**一个值**，只经纯函数 `workspaceTransition(state, action)` 改变（`src/state/transition/workspace.ts`）；
- 协调者仍只有 DeskState：`desk.workspace` 持有这个值、提供意图，并把「打开场景 / 退出场景 / 选中新文件」翻译成打开资料的动作；
- 它与 `ViewState` 不互相约束（资料区不跟随选中正是 R2.7），所以不并进 `ViewState`、不进 URL 与浏览器历史；
- 并排 / 悬浮由宽度派生（`propsPlacement`），不进状态；
- 属性栏开关按本机记住（沿用旧的面板折叠键），其余刷新即无。

旧的布局树 `PaneLayout`（方向、比例、副栏收起，按项目记在本地）连同 `SplitView` 删除：资料区固定在右侧一列，方向切换不再有意义；资料区与工作列之间的宽度比例仍可拖动，按项目记在本地（新键）。

## 否决的方案

| 方案 | 否决理由 |
|---|---|
| 属性与资料放进同一组页签（第一版原型） | 两类信息层级不同：属性只有一份且跟选中走，资料有多份且跟阅读走；切换时栏宽来回跳 |
| 属性栏永远并排 | 运行视角开资料区后画布常常不足 500px，违背 C4「画布是唯一主区」 |
| 属性栏可收成竖条（第二版原型） | 第三版改为并排 / 悬浮自动切换，竖条不再需要；关闭用 × 与「▤ 属性」 |
| 资料区状态留在呈现层（旧 `useAside` 的做法） | 预览替换、分组、关闭这些规则有了取舍，需要单测穷举；呈现层只读派生、只发意图 |
| 工作区状态并进 `ViewState` | 两者不互相约束；并进去会让资料区的每次变动都过一遍视图状态转移与 URL 同步 |

## 后果

- 规则 G15 改写；新增 WS-1–WS-10；需求 W-1、W-2（顶部）、W-4 改写。
- `split/` 目录保留（组件改名 DockPane / DockGroup / 时序图与源代码标签）：改目录名要同时改 `model/h5p-arch-desk` 的 codeRefs，而描述文件本轮归 W1，交给集成时随描述重新生成一起做。
- 属性栏内容暂时沿用 `Panel.vue`，第十七轮 W3 改为三张卡片；工具栏为「显示 ▾」预留位置，W4 落地。
- E2E 中依赖旧副栏结构（`.aside`、方向切换）的用例改为资料区的结构；新增布局 E2E。

## 待裁（「议」规则）

| 编号 | 事项 | 推荐与理由 |
|---|---|---|
| WS-2 | 属性栏开关按本机记住 | 是：老手关了属性栏多半是想一直关着；与旧面板折叠的行为一致 |
| WS-3 | 悬浮时画布适应避开卡片、右侧浮层让位 | 是：否则悬浮卡片正好盖住画布右侧的节点与「显示」面板 |
| WS-4 | 时序图只有一个标签，跟当前场景 | 是：同一时刻只有一个场景在回放，多个时序图标签只会有一个是活的 |
| WS-6 | 「取消分屏」把下组标签按固定并回上组 | 是：并回时不丢已开的资料 |
| WS-7 | 关标签后激活右邻；「▣ 资料」隐藏而不清空标签 | 是：与 VS Code 一致；关闭全部用 ✕ |
| WS-8 | 退出场景即关闭时序图标签；移动进度不切到时序图 | 是：没有场景时时序图无内容可画；切页签就是「跟随」，R2.7 不要 |
| WS-9 | 资料区每次从无到有都收起导航（而不只是会话里的第一次） | 是：与原型一致；收起不写进本机记忆，手动展开后照常 |
