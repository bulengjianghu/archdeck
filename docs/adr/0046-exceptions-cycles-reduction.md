# ADR-0046：例外口径统一并分级、环按组、传递约简决定默认画哪些线

- 状态：已采纳，已实现（第十四轮波 2：F10、F9）
- 日期：2026-10-28
- 决策人：项目负责人（2026-10-28「按推荐定稿」：F10 含补充——未解释为逐条例外、永不约简，「向上」只有一个定义，环组可选中；环内静息态只计数；F9 先用全集布局，交给 elk 只做对照实验）；起草：第十四轮主线会话
- 关联：第十三轮 91 §2（约简口径）、[ADR-0040](./0040-bundle-trunks.md)（已否决的干线）、[ADR-0031](./0031-three-views-and-structure-view.md)（束、跨界折叠）、[ADR-0043](./0043-one-word-layer-and-node-marks.md)（L37 节点注记）、[ADR-0045](./0045-one-layer-grammar.md)（远景语法）

## 背景

h5player 结构视角画出来的 303 条束里多数是环上的照画束；h5p 与 media 有四分之一左右的束可由别的路径推出。环是一组节点的属性，却被画成 N 条醒目的线；例外在声明的层与算出的层上含义不一；91 §2 的约简宇宙漏了「未解释」。

## 裁决

1. **例外一个口径**（定，K23）：例外 = 违背现行分层（声明的层写「违规」，算出的层写「向上」）∪ 环 ∪ 逆稳定 ∪ 未解释。「向上」只有一个定义：线的方向违背所在分层（位置）；结构视角判定为依赖方所在的算出的层在被依赖方之下。
2. **逐条的例外逐条常显**（定，L42①）；**只是未解释、另一端在框外或共用件架上的仍折叠计数**（议）：照画会多出 24 条（h5p）从框外进来的长线，L30 重合与标签互压上升；它照样永不约简、在界外计数与面板里。
3. **环按组**（定，L42②）：环内静息态只计数（环编号悬停、画布角），单击环编号选中环组（`sel=y:<环编号>`）画出环内、面板列成员与环内依赖；反馈边建议以后再说。
4. **传递约简**（定，K23、L42③）：91 §2 口径、宇宙不含例外；可推出的静息态不画，依赖方节点下边右「另直连 N」，聚焦一端时画出。折叠时按当前视图算（议：h5p 呈现层按全集算有 5 条可推出、按当前视图 0 条，差别只在这一层）。
5. **先用全集布局**（定）：约简不改节点位置（V12）。交给 elk 的对照实验（CLARITY_ELK=reduced）：结构视角交叉 h5p 44 → 50、h5player 238 → 239、media 8 → 8；交互视角 L30 h5player 压节点 2 → 9、media 贴框 5 → 10、h5p 重合 59 → 35 但压节点 3 → 5——互有升降、总体更差，不上线。
6. **框外结构边按实际标签文字避让**（L33 的落实）：结构视角框外边的标签原按 24 px 估宽，与「违规」「×N 元素 · 未解释」的实际宽度不符，标签互压。

## 后果

- 传递约简对 h5player 几乎没有收益（7 条），主杠杆是环按组；对 h5p 与 media 两者并重。
- 「度数大的节点聚焦时改为在另一端加标记、面板列清单」未实现：有「另直连」的节点每个中位 1 条、最多 7 条（h5p；h5player 最多 1、media 最多 2），后续按需。
