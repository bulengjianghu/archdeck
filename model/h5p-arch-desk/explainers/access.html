搬运工与两扇窗口

这一层是 接入层：。读进来的每样东西都有窗口，写出去只有一扇门，而且只许追加。

窗口与门

数据站开发服务器里的邮政窗口：项目清单带健康度，描述、源码、历史各有窗口，文件一存盘就推送更新。
描述读取凭一个约定认项目：目录里含系统卡的即是项目；当前版本、设计某一轮、对比基线都按同一约定取。
描述写入只收「人拥有」的文件：评审意见、例外、确认记录——只追加、写前比对指纹，AI 生成的部分一个字都不碰；唯一的例外是重讲：AI 的题解与讲法要求由架构台判别放行后代写，人拥有的文件照样不碰。
agent 窗口命令行与 MCP 两个外壳、一个查询核心：架构师助手写代码前先来这里问路；辅助栏的对话也从这里起一个只读的 agent 子进程。

为什么死守「只追加」：人拥有的文件是架构师的笔迹，指纹门禁守着——谁动过、什么时候动的一清二楚。
