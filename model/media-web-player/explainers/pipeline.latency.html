恒温器：读数 → 纯函数 → 动作

直播怕延迟也怕卡顿。延迟决策律 就是一台恒温器：。循环不止，直到关掉播放。

为什么把「律」单独拿出来

律是纯函数律 只算不想事：不碰浏览器、不碰时钟。想复盘某次播放为什么快进，把当时录下的读数重放一遍即可。
执行归机芯运行骨架 携带状态、把报告送到出口；读数怎么取、动作怎么落，归 自建时钟族 与 元素族 各自的执行器。
读数三件套到达抖动、画面冻结、墙钟锚点——三件互相独立，都不碰浏览器。
两族共用一条律调好一次，两台都好：恒温器的逻辑写在说明书层，不在任何一族的图纸里。

律只动脑、机芯只动手——所以想调参复盘只看律，想换实现只动执行器，两件事永远互不牵连。
