这一层是 Framework 机制内核：。它不认识任何一种播放方案——业务怎么玩，都经 Hook 与插件从外面注入。

三个通用机制

四个当黑盒的子模块怎么配合

状态机只管「当前状态 + 命令 → 下一个状态」。所有命令排一条队，一个调度循环逐条执行，谁也不能插队并行。
流水线事务只管「谁挂在带上、怎么连」。图上的任何改动都是一次差异事务：先拍快照，改坏了整体退回。
模型注册表像换台历：新模型一页页写好，翻页瞬间整体切换，旧本立刻变只读，谁也改不了。
内核门面 与 插件控制器门面把三件装配起来，事件与错误各走一条链；插件是外来能力的唯一入口。

守住的约束

    它自己不含任何播放决策：换一种玩法（直播 / 点播 / 加密）时主轴的零件不变，变的只是从外面注入的东西。
